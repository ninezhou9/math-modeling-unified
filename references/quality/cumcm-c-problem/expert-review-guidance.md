# 专家讲评与评阅机制：如何转化为可执行建议

## 1. 证据层级

### 硬规则
只来自当前年度 CUMCM 官方文件，例如论文格式、参赛纪律、AI 使用、支撑材料。

### 官方评阅机制
用于理解评委如何工作，但不等于某道新题的逐项打分表。

### 专家讲评
命题人/评阅专家对往年 C 题的复盘，具有高参考价值，但只对相似结构迁移。

### 优秀论文
用于学习结构、模型递进、图表、验证、结果叙事；不能复制文字、图、公式或结论。

## 2. 官方评阅机制带来的直接启示

2025赛区评阅规范明确：正式评阅前评委会讨论赛题、评阅要点和可能思路，形成可操作的统一细则；每篇论文至少由3位评委独立评阅；分歧大时复议；突出创新论文会被专门识别。

全国奖评阅规范进一步明确：申报本科全国一等奖论文至少由3位评委独立评阅，其他全国评阅论文至少2位；突出创新点会被推荐作为候选优秀论文。

因此论文必须满足：
- 主线可以被不同评委快速重复理解；
- 核心定义和结果不依赖“评委猜”；
- 创新不能埋在代码里，要在摘要、问题分析、模型和验证四处形成证据链；
- 图表和总括方程组降低评阅认知成本。

官方章程给出的主要评奖标准是：**假设合理性、建模创造性、结果正确性、文字表述清晰程度**。这四项比“用了什么高级算法”更稳定。

## 3. 2018–2025 C 题专家讲评的迁移价值

### 2018 邓明华：会员画像
稳定启示：指标定义与业务解释比盲目聚类更重要；画像必须可解释、能转为群体特征。

### 2019 韩中庚：机场出租车
稳定启示：先从司机/乘客真实决策与时间成本构造收益，再做策略；运营问题的评价指标必须与行为逻辑一致。

### 2020 韩中庚：中小微企业信贷
稳定启示：信用评价只是中间层，最终要进入授信额度、利率和风险收益决策；数据特征构造与模型假设要可解释。

### 2022 邓明华：古代玻璃
稳定启示：小样本统计应谨慎；分类前先分析数据结构与显著差异；不同方法结果不一致时应讨论原因，而不是只选更高准确率。

### 2023 王志勇：蔬菜定价补货
稳定启示：复杂交易数据先做口径与时间规律；关联关系、销量与定价/补货优化是递进关系，预测不能脱离最终经营目标。

### 2024 韩中庚 + 谈之奕：农作物种植策略
官方会议说明韩中庚重点讲命题背景、建模过程和具体解法，谈之奕重点综合评述评阅情况。迁移启示：大量业务约束应先被数学化，再选求解器；可行性、轮作/面积/季节等约束是否完整通常比“算法酷不酷”更重要；风险情景应在确定性基线后升级。

### 2025 崔恒建：NIPT
官方会议说明讲评覆盖命题背景、建模思路及解法要点。迁移启示：个体差异、重复测量、统计风险与判定阈值需要统一；医学/生物数据的“预测值”不应直接替代风险决策。

## 4. 如何使用专家建议

只在满足以下条件时迁移：
1. 新题的数据生成机制相近；
2. 新题的输出类型相近；
3. 迁移后能解释其必要性；
4. 不与新题约束冲突。

专家讲评中出现的算法名称不是“推荐清单”。专家真正有价值的是他们如何拆题、定义对象、建立基线、发现失效并升级模型。

## 5. 评分细则的正确用法

公开的逐题评分细则并非每年、每题都由官方公开。不要把网络流传的非官方“评分表”写成官方事实。

若获得真实赛区/命题组评分细则：
- 把每个评分点映射到论文证据：公式、图、表、结果、验证；
- 不要为了某一评分点破坏全篇主线；
- 评分细则只说明“评委看什么”，不替代数学正确性。

若没有逐项评分表，则以官方章程的四项标准和官方评阅流程为根基。
