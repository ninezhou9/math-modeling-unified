# C 题论文质量门禁

## Gate 0：题意
- [ ] 每一问都有明确输出。
- [ ] 没有自造题目没有给出的数据。
- [ ] 附件字段、单位、时间/空间范围已核对。
- [ ] 后一问与前一问的数据/参数接口写清楚。

## Gate 1：数据
- [ ] 缺失、异常、重复、口径问题有审计。
- [ ] 数据清洗不只是“调用函数”，有业务原因。
- [ ] 预测任务没有时间泄漏。
- [ ] 图表能证明后续模型选择的必要性。

## Gate 2：模型
- [ ] 先有数学对象和目标，再有算法。
- [ ] 基础模型足够简单可解释。
- [ ] 高级模型有明确升级理由。
- [ ] 优化问题的目标函数、约束和决策变量最终集中成一个模型框。
- [ ] 一般模型优先于只算题给特例。

## Gate 3：算法
- [ ] 算法与数据/模型类型匹配。
- [ ] 参数设置有依据或敏感性。
- [ ] 元启发式不是用来遮掩未建数学模型。
- [ ] 若有多个模型，比较采用统一数据切分和指标。

## Gate 4：结果
- [ ] 每问都有清晰最终答案。
- [ ] 关键数值有单位和合理精度。
- [ ] 结果不仅“表明”，还解释原因与实际含义。
- [ ] 最终策略可执行。

## Gate 5：验证
- [ ] 至少有边界/数量级检查。
- [ ] 预测/分类有合适误差指标。
- [ ] 重要决策分析参数误差是否会改变动作。
- [ ] 至少一个独立验证或稳健性证据用于核心结论。

## Gate 6：创新
- [ ] 只有 1–3 个主创新，且是真的结构/定义/一般化/不确定性/验证创新。
- [ ] 摘要能看见创新。
- [ ] 问题分析说明为什么需要创新。
- [ ] 结果/图表能量化创新收益。

## Gate 7：图表
- [ ] 每张图有明确任务。
- [ ] Overview 图无重叠、能表达信息流和模型升级。
- [ ] 图表不是全黑白灰，也不花哨。
- [ ] 同一语义同一配色。
- [ ] 坐标轴、单位、图例、caption 完整。
- [ ] 最终方案有专门图/表。
- [ ] 验证有专门图/表。

## Gate 8：论文叙事
- [ ] 摘要第1段有动机和总主线。
- [ ] 每问摘要遵循“动机→方法→核心结果→验证”。
- [ ] 关键词 ≤5。
- [ ] 问题分析不是重述。
- [ ] 每问结尾能自然进入下一问。
- [ ] 避免“为了提高准确率，我们采用更高级模型”式无证据升级。

## Gate 9：LaTeX 与页数
- [ ] 第一页仅标题+摘要+关键词。
- [ ] 问题重述从第2页开始。
- [ ] 无目录。
- [ ] 主论文25–28页（若当年规则允许）。
- [ ] 无 Overfull/Undefined references。
- [ ] 三线表、图题、表题、编号一致。
- [ ] 图表未溢出或过小。

## Gate 10：复现与合规
- [ ] `code/` 可运行，生成关键结果。
- [ ] 论文结果与代码输出一致。
- [ ] 支撑材料文件列表与实际文件一致。
- [ ] 数据来源与参考文献齐全。
- [ ] AI 使用按当年官方规则披露。
- [ ] 项目中没有学校/队员身份泄露（提交版）。
