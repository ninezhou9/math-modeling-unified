# 可视化与图表规范

当常规决策仍无法确定图型时，按需读取[详细图表选择指南](cumcm-step-review/绘图参考/chart_selection.md)；需要实现细节时再读取同目录的知识库与配方，不一次性加载全部绘图资料。

本文件是生成、排版与审核所有插图与表格的硬性执行规范。

```yaml
in_figure_title_forbidden: true
caption_position: bottom
same_chart_type_max_per_paper: 3
consecutive_same_chart_type_max: 2
journal_palettes:
  - nature
  - science
  - cell
  - ieee
  - general
  - okabe-ito
  - wong
```

## 硬性图表规范

### 1. 无图内标题（in_figure_title_forbidden）
- 图内绝对不允许出现任何主标题或副标题（图上方、图下方均不绘制文字标题）。
- 不在图像内部绘制面板编号（如 (a)、(b)）。
- 图像内部仅保留数据、轴标签（带单位）、刻度与图例。

### 2. 图题位置与正文布局
- **图题（caption）一律放在图的下方（caption_position: bottom）**，格式为 `图 X-X 图题名称`。
- **表题一律放在表格的上方**，格式为 `表 X-X 表格名称`。
- 正文必须严格依循 **"先文字引导 → 插入图表 → 紧随其后的深度分析"** 的逻辑。
- 连续两张以上图表之间若没有文字分析，判定为硬错误。

### 3. 字号比例自检
- 图中所有标签、坐标轴刻度和图例文本按印刷实际尺寸设计（正文标签 8.5–11pt，最小刻度字号 $\ge 7.5\text{pt}$）。
- 严禁用 10pt 默认小字号整图缩放，杜绝"图大字小"或模糊失真。

### 4. 图型多样性控制
- 全篇论文中，同一种图型（如纯折线图、柱状图、散点图、热力图、箱线图）**不超过 3 张（same_chart_type_max_per_paper: 3）**。
- **连续出现的同类图型不超过 2 张（consecutive_same_chart_type_max: 2）**，避免视觉疲劳。
- 综合利用组合图（如柱状-折线双轴图、箱线-散点抖动图、多子图面板）丰富表达。

### 5. 期刊配色方案（Journal Palettes）
- 内置配色集：`nature`（默认首选）、`science`、`cell`、`ieee`、`general`、`okabe-ito`（色盲友好）、`wong`。
- 严格遵循色盲友好原则：需要强对比或无障碍时优先使用 `okabe-ito`，配合线型（实线/虚线/点划线）与点标记（圆/方/三角）进行冗余编码。

### 6. 非数据图绘制（draw.io）
- 技术路线图、求解流程图、数据处理流程图、模型架构图等非数据图，统一使用 `draw.io` 绘制。
- 同样严格遵循无图内标题、图题在下、期刊配色统一的规范，导出为高清 300 DPI PNG 或矢量 PDF。

### 7. 图表面板与导出
- 导出分辨率：位图统一 $\ge 300\text{ DPI}$ PNG，优先保留矢量格式。
- 多面板布局：根据数据逻辑选择 1×2、2×1、2×2、3×1 等合理排版，保持各子图坐标刻度与比例协调。
