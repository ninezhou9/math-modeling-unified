# C 题可视化与表格设计手册

## 1. 一张图必须有任务

绘图前写一句内部目标：

> 评委看完此图，应立刻发现 ______。

若一句话填不出来，这张图大概率不值得放正文。

## 2. 总览图

不要画普通 Q1→Q2→Q3→Q4 四个矩形。总览图至少编码两类信息：
- 数据/参数如何流动；
- 模型如何升级；
- 哪个结果成为下一问约束；
- 哪些验证反向检查前面的模型。

推荐结构：

```text
原始数据 ─→ 特征/规律 ─→ 基础模型 M0 ─→ 决策模型 M1
   │              │              │               │
数据审计        机制证据         误差验证         风险/稳健性
   └──────────────────── 反馈/修正 ───────────────┘
```

使用 2–4 个低饱和颜色区分“数据、模型、结果、验证”，箭头不交叉，节点对齐，不允许文字重叠。

## 3. C 题常见高价值图

### 数据型
- 分布 + 箱线/小提琴（样本量适合时）；
- 日/周/月多尺度趋势；
- 相关矩阵只保留有解释价值的变量；
- 日历热力图、时段热力图；
- 地块/类别/群体的二维嵌入仅作为解释辅助。

### 关系型
- 散点 + 拟合 + 置信带；
- 局部效应/PDP（树模型时）；
- 边际效应图；
- 风险/概率随关键变量曲线；
- 相关网络（变量不宜过多）。

### 优化型
- **策略相图**：参数二维平面上用不同区域表示最优策略；
- **收益前沿**：收益与风险/成本的 Pareto 前沿；
- **决策矩阵热力图**：地块×年份、品类×时间、企业×额度；
- **Sankey/流图**：供应、分配、流量结构确有意义时；
- 甘特/排程图；
- 地图/空间路径图。

### 验证型
- 实测 vs 预测散点 + y=x；
- 残差 vs 拟合值；
- 误差分布/QQ；
- Bootstrap 区间/置信带；
- 交叉验证折线；
- 算法收敛曲线只在优化算法本身值得解释时出现。

## 4. “创新图”的设计原则

创新不等于 3D、渐变或复杂装饰。高价值创新图通常把两到三层信息压在一个视觉对象中。

例：
- 不只画利润柱状图，而画“参数–利润–策略切换”相图；
- 不只画预测曲线，而同时画置信带和政策阈值；
- 不只画敏感性条形图，而画“参数扰动 → 最优决策变化”的稳定区；
- 不只画聚类结果，而在每个群体旁标核心特征雷达/小倍数图（类别不多时）。

## 5. 颜色

默认方向：低饱和、学术、打印友好。

建议语义：
- 蓝：基线/模型/历史；
- 青绿：可行/最优/改善；
- 暖橙：观测/对比/需要注意；
- 暗红：风险/违反约束/异常；
- 紫灰：不确定性/辅助系列。

每张图通常不超过 4 个主色。相同语义跨全文保持同色。

避免：
- 彩虹 colormap；
- 大面积高饱和红绿；
- 纯黑白灰作为全文唯一视觉；
- 亮黄文字、霓虹色、强阴影；
- 伪 3D 柱状图。

## 6. 排版

- 正文单图常用宽度 0.68–0.85\textwidth；
- 双子图宽度 0.47–0.49\textwidth；
- 图内字体不得小到打印后不可读；
- 图例尽量放空白区或图外，不遮数据；
- 纵横轴必须有单位；
- caption 说明“图展示什么”，正文解释“图说明什么”。

## 7. 表格

所有正文表格优先三线表。

### 最终方案表
必须让评委一次看到：对象、最优动作、关键指标、必要约束或结果。

### 模型比较表
列：模型、核心假设、误差/收益、稳定性、是否采用。用来证明为什么选当前模型。

### 验证表
列：理论/基线、独立方法、差值/相对误差、结论。

### 敏感性表
若参数多，不要大表，优先热力图或 tornado/点图。

## 8. 图表选择快速表

| 信息 | 首选 |
|---|---|
| 时间趋势 | 折线/置信带 |
| 分类比例 | 100%堆积条形，类别少时饼图可用 |
| 多类别精确比较 | 水平条形/点图 |
| 两数值关系 | 散点+拟合 |
| 参数敏感性 | 曲线/热力图/策略相图 |
| 排名及不确定性 | 点图+区间 |
| 优化变量矩阵 | 热力图 |
| 网络/流量 | DAG/Sankey |
| 路径/空间 | 地图/轨迹/等高线 |
| 预测准确性 | 实测-预测 + 残差 |
| 风险收益权衡 | Pareto/前沿图 |

## 9. 禁止项

- 为丰富图表而重复画同一结论；
- 一页塞 6 张小图看不清；
- 只有图没有正文解释；
- 把 Excel 默认配色和默认标题直接截图进论文；
- 用流程图替代数学模型；
- 图中出现不一致的字体、英文大小写或小数位。
