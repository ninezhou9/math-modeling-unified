# 图论与网络分析

## Dijkstra最短路 (Dijkstra's Algorithm)

### 适用性
单源非负权图的最短路径及距离计算；城市道路导航、管道最小水头损失输送、通信路由。
### 结构或公式
松弛操作（Relaxation）：
$$\text{若 } dist[u] + w(u, v) < dist[v] \Rightarrow dist[v] \leftarrow dist[u] + w(u, v), \quad prev[v] \leftarrow u$$
### 算法专属步骤
1. **初始化**：源点 $dist[s] = 0$，其余顶点 $dist[v] = \infty$，未访问集合 $Q \leftarrow V$；
2. **堆优化提取**：从优先队列（最小二叉堆）中弹出当前距离估计值最小的顶点 $u$ 并标记为已确定；
3. **邻接边松弛**：遍历 $u$ 的所有出边 $(u, v)$，若满足松弛条件则更新 $dist[v]$ 并将其压入优先队列；
4. **循环终止**：重复提取与松弛直至队列为空或目标终点出堆；
5. **路径重构**：从终点沿前驱数组 $prev$ 反向回溯至源点并反转输出完整最优路径。
### 约束处理
严格要求全图边权非负 $w(u, v) \ge 0$；若存在负权边需改用 Bellman-Ford 或 SPFA 算法。
### 参数
数据结构实现方式（邻接表 + 最小二叉堆，时间复杂度 $O((V + E) \log V)$）。
### 验证
三角不等式全域检验 $dist[v] \le dist[u] + w(u, v)$、路径无环连通性断言。
### 风险
图存在负权边导致算法提前终止给出错误解；稠密图中使用堆优化产生额外常数开销。
### 场景
国赛 CUMCM 应急救援车队最优导航调度、管道网络最小输送阻力路线设计。
### 比较
相较于 Floyd 算法专注于单源但时间效率显著更优；相较于 A* 算法无启发函数引导，属于盲目搜索。

## Floyd-Warshall (所有节点对最短路)

### 适用性
全源最短路径、传递闭包计算、网络拓扑直径与介数中心性求解；支持含负权边（但不可含负权环）。
### 结构或公式
动态规划三重状态转移方程：
$$D_{ij}^{(k)} = \min\left(D_{ij}^{(k-1)}, \; D_{ik}^{(k-1)} + D_{kj}^{(k-1)}\right)$$
### 算法专属步骤
1. **矩阵初始化**：构造距离矩阵 $D$，若 $(i, j) \in E$ 则 $D[i][j] = w(i, j)$，对角线 $D[i][i] = 0$，其余为 $\infty$；初始化前驱矩阵 $P[i][j] = j$；
2. **三重循环迭代**：外层严格遍历中转顶点 $k \in [1..n]$，内层双重遍历起点 $i$ 与终点 $j$；
3. **松弛状态转移**：若 $D[i][k] + D[k][j] < D[i][j]$，则更新 $D[i][j] \leftarrow D[i][k] + D[k][j]$ 及 $P[i][j] \leftarrow P[i][k]$；
4. **负权回路检测**：扫描对角线，若存在 $D[i][i] < 0$ 则判定网络中存在负权环；
5. **任意两点路径重构**：根据矩阵 $P$ 递归解析任意源宿点对的最短路径序列。
### 约束处理
外层循环必须严格为中转点 $k$（循环顺序颠倒会导致动态规划阶段性无后效性破坏）。
### 参数
节点规模 $V$（时间复杂度 $O(V^3)$，空间复杂度 $O(V^2)$，推荐 $V \le 500$）。
### 验证
对角线元素检查（$D[i][i] = 0$ 且非负）、与单源 Dijkstra 抽样比对一致性。
### 风险
顶点规模 $V > 1000$ 时时间和内存开销激增导致超时溢出；存在负环时最短路无定义。
### 场景
复杂交通网络各枢纽全网最短时延计算、社交网络节点紧密度与介数中心性量化。
### 比较
算法代码极其紧凑优雅，可一次性获得全网距离矩阵；但在稀疏图上效率逊于调用 $|V|$ 次堆优化 Dijkstra。

## 最小生成树 (Prim / Kruskal)

### 适用性
构建连通所有顶点的无向加权图的最小权连通无环子图；电网铺设、通信光缆拓扑、供水管网基建。
### 结构或公式
- 生成树性质：$T = (V, E_T)$，满足 $|E_T| = |V| - 1$，连通且 $\min \sum_{e \in E_T} w(e)$
- 割切性质（Cut Property）：连接任意割切两端的最轻横切边必属于某棵最小生成树。
### 算法专属步骤
- **Kruskal 算法（加边法）**：
  1. 将图中所有边 $E$ 按权值升序排序；
  2. 初始化并查集（Disjoint Set Union），每个节点独立成集合；
  3. 顺序扫描各边 $(u, v)$，若 $\text{Find}(u) \ne \text{Find}(v)$ 则将该边并入生成树并执行 $\text{Union}(u, v)$；
  4. 选满 $|V| - 1$ 条边后终止。
- **Prim 算法（加点法）**：
  1. 设定任意起始根节点 $r$，将其加入已选集合 $S$，其余在 $V \setminus S$；
  2. 优先队列维护连接 $S$ 与 $V \setminus S$ 的所有横切边；
  3. 贪心弹出权值最小横切边 $(u, v)$，将新节点 $v$ 纳入 $S$ 并将 $v$ 的邻接边压入队列；
  4. 循环直至所有顶点加入集合。
### 约束处理
图非连通时输出最小生成森林（并查集最终连通分量 $>1$）。
### 参数
稀疏图推荐 Kruskal（$O(E \log E)$），稠密图推荐 Prim（$O(V^2)$ 或堆优化 $O(E \log V)$）。
### 验证
欧拉示性数与树性质断言（$|E_T| = |V| - 1$ 且无环）、全网连通性检验。
### 风险
带有度数上限限制（度约束生成树 DCMST）或容量限制时问题变为 NP-hard，不可直接套用贪心 MST。
### 场景
偏远山区农村供水管网最低成本主干网架规划、区域变电站互联线路拓扑。
### 比较
贪心策略可直接获得全局理论严格精确最优解；Kruskal 适合边稀疏图，Prim 适合点密集图。

## 网络流 (最大流 / 最小费用流)

### 适用性
管网/交通网通过能力极限评估、带容量限制与单位运输费用的物资最优调配；二分图匹配。
### 结构或公式
- 容量约束：$0 \le f(u, v) \le c(u, v) \quad (\forall (u, v) \in E)$
- 流量守恒：$\sum_v f(u, v) - \sum_v f(v, u) = 0 \quad (\forall u \ne s, t)$
- 最小费用最大流 (MCF)：$\min \sum_{(u,v)} cost(u, v) f(u, v)$ s.t. $\text{Flow} = \text{Flow}_{max}$
### 算法专属步骤
- **最大流 (Dinic 算法)**：
  1. 在当前流网络上构建残量网络 $G_f$；
  2. BFS 对残量网络分层，构建分层图并判断汇点 $t$ 是否可达；
  3. DFS 沿分层图寻找多条阻塞流（Blocking Flow）进行并行增广，并维护当前弧优化；
  4. 重复 BFS/DFS 过程直至残量网络中汇点不可达。
- **最小费用最大流 (Primal-Dual / 连续最短路)**：
  1. 在残量网络中以单位费用 $cost(u, v)$ 为边权（反向边费用为 $-cost$）；
  2. 使用 SPFA 或带势能标记的 Dijkstra 寻找源点 $s$ 到汇点 $t$ 的最小费用增广路；
  3. 沿最短路增广流量 $\Delta f = \min \{ c_f(u, v) \}$，同步累加费用；
  4. 循环直至不存在费用可行增广路。
### 约束处理
反向弧机制（初始反向容量为 0，反向费用为 $-cost$）提供流量回退与动态重分配能力。
### 参数
算法选择（最大流 Dinic 复杂度 $O(V^2 E)$，费用流消圈/连续最短路法）。
### 验证
最大流最小割定理验证（最大流值等于全网 $s-t$ 最小割容量）、节点流量守恒平衡断言。
### 风险
费用流网络中存在负费用环导致 SPFA 死循环（需前置消圈）；实数容量下非多项式增广可能产生无限死循环。
### 场景
原油管道网络最大吞吐量测算、灾后多点应急物资跨区域调度最小运费方案。
### 比较
运筹学经典多项式时间精确解；结构规范，可无缝映射为标准 LP 问题由线性求解器快速求解。

## 图着色 (Graph Coloring)

### 适用性
互斥资源分配、考场防冲突排考、无线电通信频道指派、寄存器分配。
### 结构或公式
映射 $c: V \to \{1, 2, \dots, k\}$，满足：
$$(u, v) \in E \Rightarrow c(u) \ne c(v), \quad \text{色数 } \chi(G) = \min k$$
### 算法专属步骤
- **DSATUR 启发式算法（饱和度优先）**：
  1. 计算图中各顶点的初始度数，选取最大度顶点染颜色 1；
  2. 计算未着色顶点的饱和度（邻接点已使用的不同颜色种类数）；
  3. 选取饱和度最大的顶点（并列时选未着色邻居度数最大者）；
  4. 给该顶点分配编号最小的可用合法颜色；若无可用颜色则新增一种颜色；
  5. 更新邻居节点的饱和度，重复步骤 2~4 直至全部着色完毕。
- **精确 0-1 整数规划求解**：引入二值变量 $x_{ic} \in \{0, 1\}$ 与 $y_c \in \{0, 1\}$，最小化 $\sum y_c$，添加邻接互斥约束 $x_{uc} + x_{vc} \le y_c$。
### 约束处理
0-1 规划建模时增加对称性破缺约束（Symmetry Breaking: $y_c \ge y_{c+1}$）大幅压缩分支定界树。
### 参数
最大允许颜色数上限 $K$、节点排列度数准则。
### 验证
遍历所有边 $(u, v) \in E$ 断言 $c(u) \ne c(v)$、检查色数满足 Brooks 定理 $\chi(G) \le \Delta(G) + 1$。
### 风险
$k$-着色判定问题（$k \ge 3$）属于 NP-complete，大规模图采用精确求解器易耗时过长。
### 场景
高校期末无冲突考试时间表编制、机场机位防冲突分配、雷达探测频率抗干扰规划。
### 比较
DSATUR 启发式在绝大多数实际工程图上可获得极其接近理论最小值的着色数；小规模图优先用 IP 精确求解。

## 社区发现 (Community Detection)

### 适用性
复杂网络模块化子群挖掘、社交网络社团划分、学术文献引用合作网聚类、系统功能拓扑区划。
### 结构或公式
模块度（Modularity）：
$$Q = \frac{1}{2m} \sum_{i,j} \left[ A_{ij} - \frac{k_i k_j}{2m} \right] \delta(c_i, c_j) \in \left[-\frac{1}{2}, 1\right]$$
其中 $m$ 为总边数，$k_i$ 为节点度数，$\delta(c_i, c_j)=1$ 当且仅当 $i, j$ 属于同一社区。
### 算法专属步骤
- **Louvain 算法（快速多级模块度优化）**：
  1. **初始化**：每个节点独立划为一个单独社区；
  2. **Phase 1（节点局部移动）**：遍历每个节点 $i$，尝试将其移入邻居节点所属社区，计算模块度增量 $\Delta Q$；将 $i$ 移入使 $\Delta Q$ 最大且为正的社区；重复遍历直至全网模块度不再提升；
  3. **Phase 2（网络社区聚合）**：将上阶段得到的每个社区压缩为一个超节点，社区内部边权转化为超节点自环权重，社区间边权转化为超节点间连接权重；
  4. **多级递归迭代**：在聚合后的新网络上重复 Phase 1 与 Phase 2，直至整个网络拓扑稳定。
### 约束处理
社区互斥性划分约束 $\bigcup C_k = V, C_i \cap C_j = \emptyset$（重叠社区需改用 Label Propagation 或 CPM）。
### 参数
分辨率参数 $\gamma$（调节划分粒度，$\gamma > 1$ 倾向于生成小社区，$\gamma < 1$ 倾向于生成大社区）。
### 验证
模块度指标 $Q$（通常 $Q > 0.3$ 表示社区结构高度显著）、标准互信息 (NMI) 与 ARI（有真实标签时）。
### 风险
模块度分辨率极限（Resolution Limit）导致算法无法识别大型网络内部的小规模致密子图；节点遍历顺序对划分细节存在轻微敏感。
### 场景
微博网络中突发舆情子群传播拓扑挖掘、金融交易洗钱团伙关联图谱检测。
### 比较
Louvain 算法在大规模网络上展现出极高的计算效率与优秀的模块度得分；较谱聚类（Spectral Clustering）速度提升数个数量级。

## 旅行商问题 (TSP, Traveling Salesperson Problem)

### 适用性
寻找遍历所有指定节点且每个节点恰好访问一次的闭合最短回路；物流配送、无人机巡检、电路板打孔。
### 结构或公式
- 目标：$\min \sum_{i} \sum_{j} c_{ij} x_{ij}, \quad x_{ij} \in \{0, 1\}$
- 进出度约束：$\sum_{j} x_{ij} = 1 \; (\forall i), \quad \sum_{i} x_{ij} = 1 \; (\forall j)$
- MTZ 子回路消除约束：$u_i - u_j + n x_{ij} \le n - 1 \quad (\forall 2 \le i \ne j \le n)$
- DFJ 子回路消除约束：$\sum_{i, j \in S} x_{ij} \le |S| - 1 \quad (\forall S \subset V, 2 \le |S| \le n-1)$
### 算法专属步骤
1. **距离矩阵构建**：计算全节点两两 Euclidean/Manhattan 距离矩阵并预排序；
2. **算法选型求解**：
   - 小规模（$n \le 25$）：状态压缩动态规划 $DP(mask, i)$ 精确求解；
   - 中规模（$n \le 100$）：MILP 配合分支割平面（Branch-and-Cut 动态回调加入违规子回路割）；
   - 大规模（$n > 100$）：LKH (Lin-Kernighan-Helsgaun) 算法或 SA / GA 配合 2-opt/3-opt 局部算子；
3. **回路闭合性验证**：检查是否构成单一包含所有顶点的完整回路。
### 约束处理
子回路消除（Subtour Elimination）是核心，必须防止形成多个孤立的局部小环。
### 参数
LKH 最大候选邻居集大小、元启发式演化代数与邻域扰动步长。
### 验证
与 Held-Karp 理论下界对比计算相对误差 Gap、节点遍历唯一性与连通性断言。
### 风险
DFJ 约束共有 $O(2^n)$ 条，严禁一次性全部加入模型，必须利用求解器回调（Lazy Constraint）动态检测添加。
### 场景
城市最后一公里快递派送顺序排布、数控机床 CNC 激光切割路径空程最小化。
### 比较
运筹学组合优化的核心基准问题；精确规划法保最优，LKH 与高级邻域搜索在大规模实例上具备极速收敛与高精度。

## 匹配问题 (Matching Problems)

### 适用性
二分图或一般图的节点双向配对、最大权指派、稳定婚配；任务分配、器官移植匹配、高校录取。
### 结构或公式
- 二分图最大权完美匹配（Kuhn-Munkres, KM 算法）：
  顶标条件：$l(u) + l(v) \ge w(u, v)$，相等子图 $E_l = \{(u, v) \mid l(u) + l(v) = w(u, v)\}$
- 稳定匹配（Gale-Shapley 算法）：
  不存在阻碍对（Blocking Pair）$(m, w)$ 使得双方比起当前配偶均更偏好对方。
### 算法专属步骤
- **KM 算法（最大权二分匹配）**：
  1. 初始化左部顶标 $l(u) = \max_v w(u, v)$，右部顶标 $l(v) = 0$；
  2. 在相等子图 $E_l$ 中使用匈牙利算法寻找完美匹配；
  3. 若未找到增广路，计算顶标微调量 $d = \min \{ l(u) + l(v) - w(u, v) \mid u \in S, v \notin T \}$；
  4. 调整顶标：$S$ 中节点顶标减 $d$，$T$ 中节点顶标加 $d$；
  5. 重复迭代直至相等子图中找到完美匹配。
- **Gale-Shapley 算法（稳定匹配）**：
  1. 初始化所有人均为单身状态；
  2. 选出一个单身男士 $m$，向其偏好列表中尚未求婚的最高顺位女士 $w$ 求婚；
  3. 若 $w$ 单身则暂时订婚；若 $w$ 已有伴侣 $m'$ 但偏好 $m > m'$，则 $w$ 接受 $m$ 并放弃 $m'$；否则拒绝 $m$；
  4. 重复直至所有人完成匹配。
### 约束处理
容量限制扩展（Hospital-Residents 模式，一个机构可接收多个申请者）。
### 参数
偏好序列表或加权二分邻接矩阵。
### 验证
霍尔婚配定理（Hall's Condition）检验完全匹配存在性、匹配结果无阻碍对稳定性断言。
### 风险
Gale-Shapley 算法存在“求婚方最优、接受方最差”的偏向性；一般图最大权匹配若误用二分图算法会导致奇环错误。
### 场景
医院住院医师规范化培训科室轮转指派、网约车平台乘客与司机实时双向撮合。
### 比较
KM 算法与匈牙利算法解决权值与基数最优化；Gale-Shapley 解决博弈论多主体偏好下的系统稳定性。
