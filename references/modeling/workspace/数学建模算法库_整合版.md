# 数学建模模型与算法库

> 用途：面向 CUMCM 赛题进行快速识别、模型选型、算法求解与结果检验。  
> 内容来源：现有《数学建模国赛常见题型及算法汇总》《2026 国赛零基础获奖速成课讲义》、CUMCM Step Review 总结及优秀论文分析材料；第 10 节为补充的启发式与元启发式算法。

## 第一部分 总体选型与建模原则

### 1. 使用原则

数学建模不能从算法名称开始。正确顺序是：

1. 明确每一问要输出数值、类别、排序、预测曲线、路径还是决策方案；
2. 将现实对象翻译为变量、参数、集合、方程、目标和约束；
3. 建立基础模型，检查是否闭合、是否可计算；
4. 根据模型结构选择精确算法、数值算法或启发式算法；
5. 设计误差检验、约束回代、灵敏度分析和基线对照；
6. 根据计算结果反查数据口径、模型假设和约束设置。

需要严格区分：

- **模型**描述问题本身，例如线性规划、SIR、TOPSIS；
- **算法**用于计算模型，例如单纯形法、遗传算法、Runge-Kutta 法；
- **检验方法**用于判断结果是否可信，例如交叉验证、残差分析、灵敏度分析。

优化问题遵循“精确方法优先”的原则：能线性化时优先线性规划；含整数或选择决策时优先整数规划；只有非凸、规模过大或组合空间难以穷举时，才使用启发式或元启发式算法。

#### 1.1 算法步骤必须按算法特征单独设计

论文中的“算法设计步骤”不能使用同一套固定模板。不同模型和算法具有不同的计算逻辑，必须根据其核心机制展开。只有“选取理由、符号解释、参数依据、结果检验”等写作要求可以共用，具体求解步骤必须分别设计。

例如：

| 模型或算法 | 应当展开的专属步骤 |
|---|---|
| 线性规划 | 定义决策变量 → 建立目标函数 → 逐项构造约束 → 确定变量取值范围 → 调用精确求解器 → 回代约束 → 分析松弛量与影子价格 |
| 整数/0-1 规划 | 定义整数或布尔变量 → 将业务规则转化为逻辑约束 → 必要时线性化 → 设置求解精度和时间限制 → 分支定界/分支割求解 → 检查最优间隙 |
| 遗传算法 GA | 确定染色体编码 → 初始化种群 → 设计适应度函数 → 选择 → 交叉 → 变异 → 可行性修复 → 精英保留 → 终止判断 |
| 差分进化 DE | 初始化实数种群 → 选择差分个体 → 差分变异 → 二项式/指数交叉 → 边界处理 → 一对一贪婪选择 → 终止判断 |
| 粒子群 PSO | 初始化粒子位置和速度 → 计算适应度 → 更新个体最优 → 更新全局最优 → 更新速度 → 更新位置 → 越界处理 → 终止判断 |
| 模拟退火 SA | 构造初始解 → 设定初温 → 生成邻域解 → 计算目标增量 → 按 Metropolis 准则接受或拒绝 → 降温 → 达到终温或稳定条件后停止 |
| 蚁群 ACO | 初始化信息素 → 根据启发因子和信息素构造路径 → 处理禁忌节点与约束 → 计算路径质量 → 信息素挥发 → 信息素增强 → 迭代停止 |
| 禁忌搜索 TS | 构造初始解 → 定义邻域移动 → 生成候选解 → 检查禁忌属性 → 应用特赦准则 → 选择当前移动 → 更新禁忌表和历史最优解 |
| 变邻域搜索 VNS | 设计多种邻域结构 → 在当前邻域中扰动 → 执行局部搜索 → 判断是否接受新解 → 改进时重置邻域 → 未改进时切换更大邻域 |
| ALNS | 构造初始可行解 → 选择破坏算子 → 移除部分决策 → 选择修复算子 → 重建可行解 → 应用接受准则 → 根据贡献更新算子权重 → 迭代停止 |
| NSGA-II | 初始化种群 → 计算多个目标 → 快速非支配排序 → 计算拥挤距离 → 锦标赛选择 → 交叉与变异 → 合并父子代 → 分层保留精英解 |
| TOPSIS | 指标方向统一 → 无量纲化 → 确定权重 → 构造加权矩阵 → 确定正负理想解 → 计算两类距离 → 计算贴近度 → 排序与稳定性检验 |
| AHP | 建立目标—准则—方案层级 → 构造两两比较矩阵 → 求特征权重 → 一致性检验 → 不通过时调整矩阵 → 层次总排序 |
| 熵权法 | 指标正向化 → 标准化 → 计算样本比重 → 计算信息熵 → 计算差异系数 → 得到权重 → 检查异常值和权重稳定性 |
| K-means | 特征选择和标准化 → 用肘部法/轮廓系数选择 K → 初始化聚类中心 → 分配样本 → 更新中心 → 判断收敛 → 解释各簇含义 |
| DBSCAN | 特征标准化 → 根据 K 距离图选择 `eps` → 设置 `min_samples` → 寻找核心点 → 密度可达扩展 → 标记噪声点 → 检查参数稳定性 |
| 逻辑回归 | 定义响应变量和特征 → 数据编码与标准化 → 构造对数似然/损失函数 → 估计系数 → 选择分类阈值 → 解释优势比 → 进行区分度与校准检验 |
| GM(1,1) | 原始序列级比检验 → 一次累加生成 → 构造背景值 → 建立灰微分方程 → 最小二乘估计参数 → 时间响应求解 → 累减还原 → 精度检验 |
| ARIMA | 绘制和分解序列 → 平稳性检验 → 差分确定 `d` → ACF/PACF 或信息准则确定 `p,q` → 参数估计 → 残差白噪声检验 → 滚动预测 |
| 微分方程模型 | 明确状态量与尺度 → 根据守恒或变化率推导方程 → 给定初始和边界条件 → 确定或反演参数 → 选择解析/数值解法 → 检查量纲、守恒和极限情形 |

写具体赛题时，上表只用于提醒算法的基本骨架，不能直接照搬。还需要结合题目重新定义编码方式、邻域算子、约束修复、损失函数、参数范围和停止条件。若采用混合或改进算法，应按真实的信息传递顺序重新组织步骤，并明确一个算法具体替换或增强了另一个算法的哪一环节。

### 2. 题型快速识别

| 题型 | 常见问法 | 核心输出 | 建模起点 |
|---|---|---|---|
| 优化类 | 最大、最小、最优、如何安排 | 决策变量及最优方案 | 变量、目标函数、约束 |
| 评价类 | 评价、比较、排序、分级 | 得分、排名或等级 | 指标含义、权重和评价规则 |
| 预测类 | 预测、估计、未来趋势 | 未来数值及不确定性 | 数据生成过程和时间结构 |
| 分类类 | 判断类别、识别状态 | 类别标签及概率 | 标签、特征和分类损失 |
| 聚类类 | 自动分组、客户分群 | 簇及簇特征 | 相似性、距离和特征尺度 |
| 机理类 | 规律、演化、传播、传热 | 状态随时间或空间的变化 | 几何、守恒、动力学和边界条件 |
| 归因类 | 哪些因素影响、贡献多大 | 影响方向和贡献度 | 因果假设、相关关系和控制变量 |

#### 19.7 从优秀论文反推算法选型

| 题目特征 | 优先考虑 | 不宜直接使用 |
|---|---|---|
| 多供应商、多指标筛选 | 熵权/AHP + TOPSIS、VIKOR、投影寻踪 | 直接凭单个指标排序 |
| 跨期订购和库存 | 动态规划、滚动优化、MILP、稳健规划 | 只按历史均值订购 |
| 离散选择与连续数量并存 | MILP、混合编码 GA、NSGA-II | 纯连续 PSO 后简单四舍五入 |
| 化学成分总和固定 | 零值替换 + CLR/ILR + 成分数据方法 | 对原百分比直接做欧氏距离和普通回归 |
| 多变量互相影响的时序 | VAR、状态空间或多变量深度时序 | 每个变量完全独立预测 |
| 节假日和多重季节性明显 | Prophet、带外生变量回归 | 随机划分训练测试集 |
| 重复测量/个体纵向记录 | LMM、广义 LMM、生存模型 | 把同一对象的多条记录视为独立样本 |
| 时间到事件且有删失 | Cox、AFT、DeepHit | 普通二分类忽略发生时间 |
| 表格型异常识别 | Logistic 基线 + LightGBM/XGBoost + 校准 | 只追求训练准确率 |
| 多目标方案选择 | ε-约束、NSGA-II、Pareto 前沿 | 未说明权重来源的简单加权 |

从这些论文可以看出，一篇完整的 C 题论文通常至少需要四层证据：数据规律和检验说明问题结构；预测或评价模型产生中间量；规划模型表达真正的决策目标与约束；求解算法获得方案并通过回测、对照、灵敏度和业务指标验证。算法越多不代表论文越好，每个算法都必须能对应一个明确的问题缺口。

## 第二部分 优化决策与运筹求解

### 3.1 线性规划（LP）

- **适用条件**：目标函数和全部约束均为线性式，决策变量允许连续取值。
- **标准结构**：在 `Ax <= b`、`x >= 0` 等约束下最大化或最小化 `c^T x`。
- **常见场景**：生产计划、配料、运输、资源分配、成本控制。
- **常用求解**：单纯形法、内点法，Python 可用 PuLP、SciPy、OR-Tools 或商用求解器。
- **优势**：可得到精确最优解、速度快、对偶解释清楚。
- **局限**：非线性关系需要合理线性化，不能为了求解方便破坏真实机制。
- **必要检验**：约束回代、松弛量、影子价格、资源上限灵敏度。

### 3.2 整数规划与混合整数规划（IP/MILP）

- **适用条件**：人数、设备数、班次数等变量必须取整数；若连续变量和整数变量并存，则为混合整数规划。
- **常见场景**：选址、排班、指派、生产批次、设施配置、运输调度。
- **常用求解**：分支定界、分支割、割平面法。
- **优势**：能够准确表达现实中的离散决策，并可给出最优性界。
- **局限**：变量和约束增多后计算量快速上升。
- **必要检验**：可行性回代、求解器最优间隙、时间上限、小规模穷举对照。

### 3.3 0-1 规划

- **适用条件**：变量只表示“选或不选、开或不开、分配或不分配”。
- **常见场景**：项目选择、站点建设、任务指派、线路选择、逻辑约束。
- **关键技巧**：使用 0-1 变量表达互斥、至少选择、至多选择、先后依赖及 Big-M 逻辑。
- **风险**：Big-M 过大会降低求解效率，过小会错误排除可行解。

### 3.4 非线性规划（NLP）

- **适用条件**：目标或约束中存在平方、乘积、指数、根号、分式等非线性结构。
- **常见场景**：参数反演、轨迹优化、物理结构优化、曲面极值。
- **常用求解**：梯度下降、牛顿法、拟牛顿法、序列二次规划、信赖域法；非凸或不可导时可用元启发式算法。
- **风险**：可能存在多个局部最优，结果依赖初始值。
- **必要检验**：多初值运行、边界检查、梯度或 KKT 条件、与粗网格搜索对照。

### 3.5 多目标规划

- **适用条件**：同时存在成本、收益、风险、时间等相互冲突的目标。
- **常用处理**：加权求和、目标规划、ε-约束法、分层优化、Pareto 前沿、NSGA-II。
- **输出**：通常不是唯一答案，而是一组非支配解及其权衡关系。
- **风险**：直接加权会受到目标量纲和权重主观性的影响。
- **必要检验**：目标标准化、权重敏感性、Pareto 解覆盖度和方案可解释性。

### 3.6 组合优化

- **适用条件**：从有限但数量巨大的排列、组合、匹配或路径集合中寻找最优方案。
- **典型问题**：旅行商 TSP、车辆路径 VRP、装箱、指派、工序排序、课程排布。
- **求解选择**：小规模用动态规划、整数规划、分支定界或穷举；大规模使用问题专属启发式和元启发式算法。
- **必要检验**：小规模精确解、上下界、基准方案、运行时间和重复运行稳定性。

### 3.7 常用运筹模型补充

| 模型 | 典型用途 | 常用求解 |
|---|---|---|
| 动态规划 | 多阶段决策、背包、最短路径 | 状态转移和递推 |
| 网络最短路 | 运输、路线、通信路径 | Dijkstra、Floyd、Bellman-Ford |
| 最小生成树 | 最低成本连通网络 | Prim、Kruskal |
| 最大流/最小费用流 | 运输能力、任务分配、网络调度 | 增广路、网络单纯形 |
| 指派模型 | 人员—任务一一匹配 | 匈牙利算法、整数规划 |
| 排队模型 | 等待时间、服务台配置 | M/M/1、M/M/c 等 |
| 库存模型 | 订货量、缺货和持有成本 | EOQ、动态库存规划 |

### 9. 资料中已有的元启发式算法

#### 9.1 遗传算法（GA）

- **思想**：通过选择、交叉和变异在种群中迭代搜索。
- **适用**：离散、连续、非凸、不可导及混合编码问题，通用性强。
- **基本步骤**：编码 → 初始化种群 → 计算适应度 → 选择 → 交叉 → 变异 → 精英保留 → 停止。
- **优势**：全局搜索能力较强，容易与具体问题结合。
- **局限**：计算较慢，参数较多，可行解修复和编码质量影响很大。
- **检验**：收敛曲线、多随机种子重复、小规模精确解对照、最优值均值和标准差。

#### 9.2 粒子群算法（PSO）

- **思想**：粒子根据自身历史最优和群体最优更新速度与位置。
- **适用**：连续参数优化、非线性函数寻优和参数反演。
- **优势**：结构简单、参数较少，通常比 GA 收敛快。
- **局限**：后期可能早熟，离散问题需要重新定义位置和更新规则。
- **改进方向**：惯性权重衰减、速度限制、随机扰动、局部拓扑。

#### 9.3 模拟退火（SA）

- **思想**：以一定概率接受较差解，使搜索能够跳出局部最优；接受概率随温度下降而减小。
- **适用**：TSP、排序、布局、调度等组合优化，也可处理连续优化。
- **关键设置**：初始温度、降温系数、每个温度的迭代次数和邻域结构。
- **优势**：实现简单，有跳出局部最优的能力。
- **局限**：降温过快易早熟，降温过慢耗时很长。

#### 9.4 NSGA-II

- **思想**：利用快速非支配排序、拥挤距离和精英保留求解多目标优化。
- **适用**：多个相互冲突目标且需要获得 Pareto 解集的问题。
- **输出**：非支配方案集合，而非单个所谓“综合最优解”。
- **检验**：可行率、Pareto 前沿分布、收敛性、覆盖范围及代表方案解释。

### 10. 新增的启发式与元启发式算法

#### 10.1 贪心算法

- **性质**：问题专属构造启发式，不属于通用元启发式。
- **思想**：每一步选择当前看起来最优的动作，快速得到一个完整方案。
- **适用**：路径构造、任务分配、装箱、排程的初始解或基准方案。
- **优势**：速度快、逻辑清楚、容易解释。
- **局限**：局部最优选择不保证全局最优。
- **竞赛作用**：既可以单独作为简单算法，也可以为 GA、SA、TS、VNS 和 ALNS 提供高质量初始解。

#### 10.2 局部搜索（LS）

- **思想**：从一个可行解出发，在邻域中反复寻找更优解，直到没有改进。
- **常见邻域**：交换、插入、逆序、2-opt、3-opt、任务移位。
- **适用**：路径、排序、排班、选址和调度。
- **优势**：实现简单，能快速改善现有解。
- **局限**：容易停在局部最优，结果强烈依赖初始解和邻域设计。
- **常见组合**：贪心 + 2-opt；GA + 局部搜索；随机重启局部搜索。

#### 10.3 蚁群算法（ACO）

- **思想**：人工蚂蚁根据启发信息和信息素概率选择路径，优质路径获得更多信息素并被后续搜索强化。
- **适用**：TSP、VRP、网络路由、工序排序等图和路径问题。
- **关键参数**：信息素权重、启发信息权重、挥发率、蚂蚁数量。
- **优势**：天然适合离散路径构造，正反馈可逐步强化好路径。
- **局限**：早期搜索可能较慢，信息素过度集中会导致早熟。
- **必要检验**：不同参数与随机种子、多次运行稳定性、与最近邻和 2-opt 基线对照。

#### 10.4 禁忌搜索（TS）

- **思想**：在局部搜索基础上设置禁忌表，暂时禁止返回近期访问过的操作或解，并用特赦准则保留特别优秀的移动。
- **适用**：排班、选址、车辆路径、工序调度和组合指派。
- **核心设计**：邻域、禁忌对象、禁忌长度、候选集合和特赦准则。
- **优势**：能够减少循环并越过局部最优，适合有成熟邻域结构的问题。
- **局限**：不同问题需要专门设计禁忌规则，参数不合适会限制有效搜索。

#### 10.5 差分进化（DE）

- **思想**：利用种群中个体的差分向量产生变异，再通过交叉和选择更新种群。
- **适用**：连续、非线性、非凸、不可导的参数优化。
- **关键参数**：种群规模、缩放因子 F、交叉概率 CR。
- **优势**：结构简单，全局搜索性能通常较稳定，连续优化中常可作为 PSO 和 GA 的对照。
- **局限**：约束处理和参数范围设置仍然重要，高维问题计算量较大。
- **必要检验**：多次独立运行、函数评价次数统一、与 PSO/GA 在同预算下对比。

#### 10.6 变邻域搜索（VNS）

- **思想**：系统地切换不同邻域，通过“扰动—局部搜索—接受”跳出单一邻域的局部最优。
- **适用**：TSP、VRP、排班、调度和选址等离散组合问题。
- **优势**：不依赖复杂群体机制，效果主要来自问题专属邻域，容易嵌入业务约束。
- **局限**：邻域设计决定算法上限；邻域过多会增加计算成本。
- **必要检验**：报告各邻域定义，并通过消融比较单邻域和多邻域效果。

#### 10.7 大邻域搜索与自适应大邻域搜索（LNS/ALNS）

- **思想**：每轮破坏当前解的一部分，再用修复算子重新构造；ALNS 根据历史效果动态调整不同破坏和修复算子的选择概率。
- **适用**：大规模 VRP、带时间窗路径、复杂排班、配送和生产调度。
- **常见破坏算子**：随机移除、最差移除、相关性移除、区域移除。
- **常见修复算子**：贪心插入、最小增量插入、Regret-k 插入。
- **优势**：能够一次改变解的较大结构，处理复杂约束和大规模问题时很强。
- **局限**：实现工作量较大，需要设计多种算子、可行性修复和自适应评分机制。
- **必要检验**：算子使用频率、改进贡献、可行率、运行时间和与普通局部搜索/VNS 的对照。

### 11. 启发式算法选型表

| 问题结构 | 首选算法 | 可对照算法 | 主要原因 |
|---|---|---|---|
| 连续非凸参数优化 | DE、PSO | GA、SA | 编码自然，连续搜索效率较高 |
| 一般混合变量优化 | GA | SA、问题专属混合算法 | 编码灵活，可处理多种变量 |
| 单目标路径规划 | ACO、VNS | GA、SA、TS | 路径和邻域结构容易表达 |
| 大规模 VRP/带时间窗路径 | ALNS | VNS、TS、MILP 小规模基准 | 破坏—修复适合复杂约束 |
| 排班与工序调度 | TS、VNS、ALNS | GA、SA | 交换、插入等邻域明确 |
| 多目标优化 | NSGA-II | ε-约束法、加权法 | 能直接输出 Pareto 解集 |

### 12. 约束处理方法

启发式算法不会自动满足约束，必须明确采用哪种处理方式：

1. **可行编码**：编码时保证生成的每个个体都满足约束；
2. **修复算子**：发现超容量、时间冲突等问题后进行删除、插入或调整；
3. **罚函数**：将违反约束的程度加入目标函数；
4. **可行解优先规则**：可行解优于不可行解，在同类解中再比较目标值；
5. **解码器**：个体只表示优先级，由解码过程构造可行方案。

论文中不能只写“设置惩罚项”，还要给出惩罚公式、系数来源及其敏感性。

### 13. 启发式算法统一验证规范

任何启发式或元启发式结果至少完成以下检查：

- **基线**：与贪心、随机方案或题目原方案比较；
- **精确对照**：缩小问题规模后，用穷举、动态规划或整数规划求精确最优解；
- **公平预算**：不同算法使用相近的函数评价次数或运行时间；
- **重复实验**：建议使用多个随机种子，报告最优值、均值、标准差和最差值；
- **收敛过程**：绘制最优值随迭代次数或计算时间的变化；
- **可行性**：将最终方案逐项代回所有硬约束；
- **参数敏感性**：改变种群规模、迭代次数或关键参数，观察结果是否稳定；
- **消融实验**：改进算法应去掉新增算子或机制，验证改进确实有效；
- **运行成本**：报告硬件环境、运行时间和停止条件。

不能因为收敛曲线变平就声称得到全局最优。若没有最优性证明，应写“获得当前计算预算下的最好可行解”或“得到近似最优方案”。

### 14.5 优化模型的约束右端扰动

对于约束：

$$
a_i^{\mathsf T}x\le b_i,
$$

改变资源上限：

$$
b_i'=b_i(1+\delta),
$$

重新求解优化模型，比较：

- 最优目标值；
- 决策变量；
- 紧约束和松弛约束；
- 资源利用率；
- 最优方案是否切换；
- 不可行情况是否出现。

资料用 $\pm20\%$ 作为示例。真实范围应由资源可能变化范围确定。推荐图为资源上限—目标值折线图、方案结构堆叠图，以及两个资源同时变化时的热力图。

### 14.6 影子价格分析

线性规划中，资源约束右端增加一个单位所带来的最优目标值增量，可近似表示为：

$$
\lambda_i\approx\frac{Z(b_i+\Delta b_i)-Z(b_i)}{\Delta b_i}.
$$

资料中的示例是将资源从100增加到101，重新求最大利润。影子价格主要回答：

- 哪种资源最值得增加；
- 新增一单位资源可以提高多少收益；
- 在什么范围内该边际价值保持不变。

影子价格只在允许增减范围内有效。超过范围后，最优基可能变化，应重新求解，不能无限外推。

启发式算法与精确解对照时，可计算相对最优间隙。对于最小化问题：

$$
\operatorname{Gap}=\frac{f_{\mathrm{alg}}-f_{\mathrm{exact}}}{\left|f_{\mathrm{exact}}\right|}\times100\%.
$$

其中，$f_{\mathrm{alg}}$ 为启发式算法得到的目标值，$f_{\mathrm{exact}}$ 为小规模精确解或已知最优值。最大化问题应按目标方向调整分子，保证 Gap 越小表示结果越接近基准最优值。

随机算法不能只报告最好的一次结果。建议在相同计算预算下独立运行多次，至少给出：

$$
\mathrm{Best},\quad \mathrm{Mean},\quad \mathrm{Std},\quad \mathrm{Worst},\quad \mathrm{Time}.
$$

若篇幅有限，正文保留 Best、Mean、Std 和运行时间，完整运行结果放入附录。

#### 2021 年模型设计步骤

1. 按周统计供应商的供货次数、平均供货量、波动系数、订单完成率、断供次数和材料类别。
2. 对指标正向化、标准化，并用熵权-TOPSIS、AHP-TOPSIS或投影寻踪得到供应商得分。
3. 依据得分和最低供应能力筛选候选供应商，避免把全部供应商直接放入大规模优化模型。
4. 定义供应商选择变量、订购量变量和转运量变量，建立成本、损耗、库存、需求满足与运输能力约束。
5. 线性且规模可控时使用 MILP；非线性、多目标或规模过大时，再使用 GA、PSO、动态规划或贪心算法。
6. 对供货量、损耗率、产能和运输能力进行扰动，检查供应商名单及订购方案是否稳定。

## 第三部分 综合评价与排序

### 4.1 AHP 层次分析法

- **作用**：依靠专家或决策者的两两比较确定主观权重。
- **步骤**：建立层级结构，构造判断矩阵，计算权重，进行一致性检验。
- **适用**：数据缺少、指标不宜完全客观量化、指标数量不多的场景。
- **必要检验**：一致性比例 `CR < 0.1`；不通过时调整判断矩阵。
- **风险**：主观性较强，不能把人为赋值包装为客观结论。

### 4.2 熵权法

- **作用**：根据指标在样本间的离散程度计算客观权重。
- **步骤**：指标正向化和标准化，计算样本比重、信息熵、差异系数和权重。
- **适用**：具有完整量化数据的多指标评价。
- **风险**：波动大不一定等于实际重要，异常值可能放大权重。
- **必要检验**：异常值处理、不同标准化方式对比、权重扰动。

### 4.3 TOPSIS

- **作用**：根据方案与正理想解、负理想解的距离计算贴近度并排序。
- **适用**：多方案、多指标且含正向和负向指标的综合排序。
- **注意**：TOPSIS 本身不负责确定权重，通常与 AHP 或熵权法组合。
- **必要检验**：权重敏感性、排序稳定性、与简单加权评分对照。

### 4.4 模糊综合评价

- **作用**：通过隶属度将“优秀、一般、较差”等模糊概念转化为可计算等级。
- **步骤**：确定因素集和评价集，构造隶属度矩阵，确定权重并进行模糊合成。
- **适用**：满意度、风险等级、舒适度、质量等级等边界模糊的问题。
- **风险**：隶属函数和等级边界可能带有主观性。
- **必要检验**：改变隶属函数或阈值后检查等级是否稳定。

### 4.5 机器学习评价

- **资料涉及模型**：随机森林、BP 神经网络、支持向量机。
- **适用**：存在较多已标记样本，希望学习指标与等级之间的非线性关系。
- **优势**：可处理复杂关系；随机森林还可输出特征重要性。
- **风险**：需要可靠标签和足够样本，黑箱预测不能代替指标含义解释。
- **必要检验**：训练/验证/测试划分、交叉验证、混淆矩阵、AUC、F1 和解释分析。

### 4.6 评价模型常用组合

- 少数据、依赖专家判断：AHP + TOPSIS；
- 有较完整客观数据：熵权法 + TOPSIS；
- 定性等级明显：AHP/熵权法 + 模糊综合评价；
- 大样本且有标签：机器学习模型与传统评价模型对照。

### 14.4 TOPSIS与综合评价的权重扰动

资料中给出的典型方法是将每个指标权重分别上调和下调，再重新归一化：

$$
w_j'=w_j(1+\delta),
$$

$$
\widetilde w_k=\frac{w_k'}{\sum_{r=1}^{m}w_r'}.
$$

对每次扰动重新计算TOPSIS正负理想解、距离和贴近度，记录：

- 各方案贴近度变化；
- 第一名和前几名是否改变；
- 完整排名是否稳定；
- 哪个权重最容易引起排名反转。

除排名保持率外，还可使用Spearman或Kendall等级相关系数比较扰动前后的排序。资料中的 $\pm10\%$ 是教学示例，实际幅度应根据权重来源和判断误差确定。

推荐图为贴近度变化折线图、排名变化图和权重—排名热力图。雷达图不能替代排名稳定性检验。

| 模型 | 必选评估指标 | 首选图 | 条件允许时增加 |
|---|---|---|---|
| AHP | 各指标权重、CI、CR | 权重柱状图 | 权重扰动下的排名变化图 |
| 熵权法 | 信息熵、差异系数、最终权重 | 权重柱状图 | 标准化数据热力图、异常值处理前后权重对比 |
| TOPSIS | 正负理想解距离、贴近度、最终排名 | 贴近度排序条形图 | 权重变化下的排名稳定性图 |

评价模型的重点不是让雷达图好看，而是证明权重、得分和排名稳定。雷达图只在指标数量适中、确实需要展示方案特征差异时使用，不作为模型有效性的主要证据。

## 第四部分 分类、聚类与统计判别

### 5. 分类模型

#### 5.1 逻辑回归

- **适用**：二分类概率预测，需要较强可解释性时作为首选基线。
- **核心**：用线性函数拟合对数几率，再通过 Sigmoid 映射为概率。
- **优点**：系数方向和优势比容易解释，训练快。
- **局限**：原始形式只能形成线性决策边界。
- **检验**：ROC-AUC、混淆矩阵、精确率、召回率、F1、校准曲线。

#### 5.2 支持向量机（SVM）

- **适用**：小到中等样本、高维特征，或需要核函数处理非线性边界。
- **注意**：对变量尺度敏感，训练前通常必须标准化。
- **局限**：大样本计算较慢，核函数模型解释性较弱。

#### 5.3 随机森林

- **适用**：非线性关系、变量交互、混合特征，分类和回归都可使用。
- **优势**：抗过拟合能力较好，可输出特征重要性。
- **风险**：重要性不等于因果贡献；类别极不平衡时仍需处理采样或阈值。

#### 5.4 BP 神经网络

- **适用**：样本较多、关系复杂、传统模型拟合不足。
- **风险**：参数多、初值敏感、可解释性较低，小样本容易过拟合。
- **检验**：独立测试集、学习曲线、多次重复训练和消融实验。

#### 5.5 分类通用流程

缺失值处理 → 类别编码 → 必要时标准化 → 分层划分数据 → 建立简单基线 → 训练候选模型 → 阈值和指标评价 → 特征解释。

类别不平衡时不能只报告准确率，应重点观察召回率、精确率、F1、PR-AUC，并说明类别权重或采样方法。

### 6. 聚类模型

#### 6.1 K-means

- **适用**：已知或能够估计簇数，簇近似球形且尺度接近。
- **步骤**：标准化，使用肘部法或轮廓系数确定 K，多次初始化后聚类。
- **局限**：对初始中心、异常值和非球形簇敏感。

#### 6.2 层次聚类

- **适用**：小到中等数据，希望通过树状图观察层级结构和选择簇数。
- **关键选择**：距离度量与 linkage 方法。
- **局限**：大样本计算和存储成本较高。

#### 6.3 DBSCAN

- **适用**：簇形状不规则、无需预设簇数且希望识别噪声点。
- **关键参数**：邻域半径 `eps` 与最小样本数 `min_samples`。
- **局限**：密度差异很大的数据难以用一组参数处理。

#### 6.4 聚类检验

- 内部指标：轮廓系数、Calinski-Harabasz、Davies-Bouldin；
- 稳定性：改变初始值、样本或参数后比较聚类一致性；
- 外部解释：每个簇必须对应可说明的现实特征，不能只给编号。

### 15.3 分类模型

分类模型至少报告混淆矩阵、Precision、Recall、F1 和 ROC-AUC。若正负样本严重不平衡，应将 PR-AUC 放在 ROC-AUC 之前，不能用 Accuracy 作为唯一指标。

| 任务情况 | 重点指标 | 首选图 |
|---|---|---|
| 类别相对均衡 | Accuracy、Precision、Recall、F1、ROC-AUC | 混淆矩阵、ROC 曲线 |
| 少数类识别很重要 | Recall、Precision、F1、PR-AUC | 混淆矩阵、PR 曲线 |
| 输出概率用于决策 | Log-loss、Brier Score、校准误差 | 校准曲线 |
| 需要解释变量作用 | 回归系数/优势比、置换重要性或 SHAP | 系数置信区间图、特征重要性图 |

多个分类器比较时，应使用相同的数据划分或交叉验证折，不能让不同算法使用不同测试集。

### 15.5 聚类模型

| 模型 | 必选评估指标 | 首选图 | 参数选择图 |
|---|---|---|---|
| K-means | 轮廓系数、CH 指数或 DB 指数、各簇样本量 | PCA/UMAP 二维聚类图 | 肘部曲线和不同 $K$ 的轮廓系数图 |
| 层次聚类 | 轮廓系数、各簇样本量、重复抽样稳定性 | 聚类树状图 | 不同截断高度下的聚类对比 |
| DBSCAN | 轮廓系数、噪声点比例、簇数稳定性 | 降维聚类图并单独标记噪声点 | K 距离曲线和参数敏感性热力图 |

聚类没有标签时，内部指标只能辅助选择参数。最终必须解释每个簇的现实特征，并检查改变样本、随机种子或关键参数后分群是否稳定。

### 19.2 2022 年 C 题：古代玻璃制品成分分析

玻璃化学成分属于成分数据，满足各成分非负且总和接近 100%。某一成分增加会迫使其他成分相对减少，因此不能直接把原百分比当作相互独立的普通变量。核心处理是先解决缺失值、零值和定和约束，再进行回归、分类与关联分析。

|---|---|---|---|---|
| C155 | CLR 中心化对数比变换 | 将各化学成分百分比转为相对含量变量 | 消除定和约束造成的伪相关，使后续回归和距离分析更合理 | CLR 变量和成分相对变化结果 |
| C155 | 卡方检验 | 检验表面风化与玻璃类型、纹饰、颜色是否相关 | 两个变量均为分类变量 | 卡方统计量、自由度、p 值和关联结论 |
| C155 | 多元线性回归 | 根据风化前后成分关系预测风化前化学成分 | 输出为连续成分含量，需要解释多个成分的共同影响 | 回归系数、预测值、残差和拟合优度 |

| C065 | CLR + 多元回归 | 预测风化前后成分的相对变化 | 回归对象是成分数据，必须先变换 | 成分还原值和预测误差 |
| C065 | 层次聚类 | 从大量成分中筛选具有代表性的变量 | 样本较少，层次结构比预先指定簇数更容易解释 | 聚类树和代表成分 |
| C065 | 决策树-SVM 集成 | 识别高钾、铅钡及其亚类 | 决策树可解释，SVM适合小样本高维分类，组合可降低单模型偏差 | 类别概率、混淆矩阵和分类准确率 |
| C065 | PCA/特征值分解 | 分析不同成分之间的共同变化并绘制双标图 | 成分变量多且相关性强，需要降维展示 | 主成分、载荷、解释方差和双标图 |
| C229 | 乘法替换法 | 处理化学成分中的零值后再做对数比变换 | CLR 中不能直接对零取对数，且简单加常数会扭曲比例结构 | 替换后的成分数据 |
| C229 | Aitchison 几何 | 在成分数据空间中计算距离、均值和变化关系 | 欧氏距离不适合定和成分数据 | Aitchison 距离及成分相对差异 |
| C229 | Spearman + 卡方检验 | 分析风化程度、类型、纹饰和颜色的关系 | 同时包含有序/连续关系和分类关系 | 相关系数、卡方检验结果 |
| C229 | 决策树 + PLS-DA | 对玻璃类型进行分类并比较不同分类器 | PLS-DA 适合高维共线数据，决策树提供明确判定规则 | 分类规则、投影得分、准确率和重要变量 |

#### CLR 变换的专属步骤

设样品的成分向量为 $\mathbf{x}=(x_1,\ldots,x_D)$，几何均值为

$$
g(\mathbf{x})=\left(\prod_{j=1}^{D}x_j\right)^{1/D},
$$

则

$$
\operatorname{clr}(x_j)=\ln\frac{x_j}{g(\mathbf{x})}.
$$

实际使用顺序必须是：检查总和与异常记录 → 处理缺失值 → 对零值做乘法替换 → 闭合到 100% → CLR 变换 → 回归、聚类或分类 → 将预测结果反变换回百分比空间。不能先把零直接改成任意小数，再跳过闭合处理。

建议报告：分类准确率、宏平均 F1、混淆矩阵、交叉验证结果、回归 RMSE、成分和是否接近 100%、聚类轮廓系数及敏感性分析。建议绘制 CLR 后箱线图、聚类树、PCA 双标图、混淆矩阵和预测—真实成分对比图。

## 第五部分 回归、预测与时序决策

### 7. 预测模型

#### 7.1 回归模型

- **线性回归**：适合趋势近似线性、特征与目标关系较清楚的情况；
- **Ridge**：通过 L2 正则缓解多重共线性；
- **Lasso**：通过 L1 正则进行收缩和变量筛选；
- **非线性回归**：当机理或散点形态支持指数、幂函数、Logistic 等关系时使用。

检验包括残差、异方差、多重共线性、训练与测试误差、交叉验证和预测区间。

#### 7.2 灰色预测 GM(1,1)

- **适用**：数据点较少、序列较平滑且大致呈单调指数趋势。
- **步骤**：级比检验，一次累加生成，建立一阶灰微分方程，估计参数并还原预测。
- **优势**：小样本条件下实现简单。
- **局限**：对剧烈波动、周期性和结构突变不适用。
- **检验**：级比检验、残差、相对误差、后验差检验及滚动预测。

#### 7.3 ARIMA

- **适用**：数据量相对充足的单变量时间序列，常见参考是至少约 30 个时点。
- **步骤**：平稳性检验和差分，结合 ACF/PACF 或信息准则选阶，拟合并检查残差白噪声。
- **优势**：结构清楚，可给出预测区间。
- **局限**：结构突变、强非线性和复杂多重季节性需要扩展模型。

#### 7.4 预测模型选择

- 4—10 个点且趋势较单调：考虑 GM(1,1)；
- 数据点较多且具有时间依赖：考虑 ARIMA；
- 多个解释变量预测一个目标：考虑回归、随机森林等监督模型；
- 先建立简单基线，再决定是否需要复杂机器学习或神经网络。

时间序列必须按照时间先后划分训练集和测试集，不可随机打乱；推荐使用滚动回测评价稳定性。

### 15.4 回归与预测模型

| 模型 | 必选评估指标 | 首选图 | 必要诊断图 |
|---|---|---|---|
| 一般回归 | MAE、RMSE、$R^2$；比例误差有意义时增加 MAPE | 真实值—预测值图 | 残差—拟合值图；进行统计推断时增加 Q-Q 图 |
| GM(1,1) | 级比检验、相对误差/MAPE、后验差比 $C$、小误差概率 $P$ | 原始值、拟合值和预测值曲线 | 相对误差或残差图 |
| ARIMA | AIC/BIC、测试集 MAE/RMSE/MAPE、Ljung-Box 检验 | 真实值与预测区间图 | 定阶时画 ACF/PACF；拟合后画残差 ACF |
| 机器学习预测 | 测试集 MAE、RMSE、$R^2$，交叉验证均值和标准差 | 真实值—预测值图 | 学习曲线或特征重要性图 |

预测模型必须优先报告样本外误差。时间序列采用滚动回测或按时间顺序留出测试集，不能把训练集拟合误差当成预测能力。

#### 预测—优化联动步骤

1. 按品类或单品汇总日销量、售价、批发价、折扣、退货与损耗率。
2. 绘制趋势、季节图和 ACF/PACF，按时间顺序划分训练集与测试集。
3. 使用 ARIMA、Prophet、VAR、LSTM 等预测销量和成本，并通过滚动回测选择模型。
4. 建立价格—需求函数。能解释时优先使用线性、半对数或双对数模型，不应只靠黑箱预测器生成价格。
5. 定义是否上架、补货量和定价变量，以利润最大、损耗最小或需求满足最大为目标。
6. 加入单品数量、最低陈列量、损耗、可售库存、价格范围和预算约束。
7. 精确规划可解时优先 MILP/MIQP；连续非凸时可用 SA/PSO；多目标混合编码时使用 NSGA-II。
8. 用实际历史日进行回测，并对需求预测误差、进价和损耗率做情景分析。

建议报告：样本外 MAE/RMSE/MAPE、价格弹性显著性、总利润、需求满足率、损耗量、缺货率、单品数量和算法稳定性。建议绘制真实值—预测值图、残差 ACF、价格—销量拟合图、补货量曲线、利润收敛曲线和 Pareto 前沿。

#### 线性混合效应模型（LMM）的专属步骤

对孕妇 $i$ 的第 $j$ 次检测，可写为

$$
y_{ij}=\mathbf{x}_{ij}^{\mathsf T}\boldsymbol\beta+
\mathbf{z}_{ij}^{\mathsf T}\mathbf{b}_i+\varepsilon_{ij},
$$

其中 $\boldsymbol\beta$ 为总体固定效应，$\mathbf{b}_i$ 为孕妇层随机截距或随机斜率。具体步骤为：绘制每位孕妇的纵向轨迹 → 确定固定效应和非线性项 → 从随机截距模型开始 → 根据似然比检验增加随机斜率 → 用 REML 估计最终方差参数 → 检查残差与随机效应分布 → 计算 ICC → 生成总体及个体预测曲线。不能把同一孕妇的多次记录当成独立样本随机拆分训练集和测试集。

建议报告：固定效应估计与置信区间、似然比检验、AIC/BIC、ICC、边际/条件 $R^2$、预测 RMSE、推荐时点误差、异常识别 AUC、灵敏度、特异度、F1及校准度。建议绘制个体轨迹图、LMM 拟合曲线与置信带、BMI—孕周推荐热力图、风险函数曲线、ROC/PR曲线、校准曲线和 SHAP 图。

## 第六部分 机理、归因与动态系统

### 8. 机理与归因模型

#### 8.1 因果归因分析

- **资料涉及方法**：偏相关分析、灰色关联、回归系数归因、SHAP 值。
- **适用**：因素识别、风险溯源、影响方向与贡献度分析。
- **注意**：相关性、模型重要性和 SHAP 值本身不能自动证明因果关系。
- **必要检验**：控制混杂因素、共线性检验、稳健性分析，并明确结论是“关联”还是“因果”。

#### 8.2 微分方程机理模型

- **适用**：运动、传热、扩散、种群增长、衰减、传播等连续动态过程。
- **构建顺序**：确定状态量 → 根据守恒或变化率关系建立方程 → 给定初始/边界条件 → 估计参数 → 数值求解。
- **常用数值法**：Euler 法、Runge-Kutta 法、有限差分法等。
- **必要检验**：量纲一致性、守恒关系、极端情形、边界条件、参数灵敏度和实测数据对照。

#### 8.3 SIR 传播模型

- **状态变量**：易感者 S、感染者 I、移除者 R。
- **核心参数**：传播率、恢复率及基本再生数。
- **适用**：封闭人群中的基础传播过程。
- **扩展**：存在潜伏期时可用 SEIR；还可加入出生死亡、隔离、接种、时变参数和空间传播。
- **必要检验**：人数守恒、参数来源、峰值时间、观测数据拟合和政策参数敏感性。

#### 8.4 结构机理分析

- **作用**：将复杂系统拆为模块、层级和相互作用关系。
- **常用表达**：结构拆解图、拓扑关系、模块输入输出、层级机理框架。
- **注意**：单纯画框图通常不足以完成定量建模，应继续落实为变量、规则或方程。

#### 8.5 系统动力学（SD）

- **适用**：生态、经济、人口、供应链等具有反馈、存量和流量的长期动态系统。
- **步骤**：绘制因果回路，确定存量和流量，建立状态方程，进行情景模拟。
- **优势**：能表示正负反馈和政策的长期影响。
- **局限**：更适合宏观趋势，不适合要求微观高精度的任务。
- **必要检验**：结构验证、历史拟合、极端条件测试、参数灵敏度和情景对比。

### 14.7 机理模型参数敏感性

机理模型重点改变初始条件、边界条件和物理参数，并重新进行数值求解。例如：

- 热传导：环境温度、热传导率、材料厚度、换热系数；
- 运动模型：初速度、阻力系数、质量、角度；
- 种群模型：增长率、承载量、初始种群；
- 传播模型：传播率、恢复率、潜伏期和初始感染人数。

应观察状态曲线、峰值、峰值时间、累计量、守恒误差和边界是否满足。参数来自文献时，要说明范围；参数由数据反演时，要说明估计方法和不确定性。

### 14.8 SIR/SEIR传播率情景分析

资料中的SIR案例改变传播率 $\beta$：

$$
\beta\in\{0.15,0.30,0.50\},
$$

分别表示严格防控、基准状态和无防控状态。每个情景重新求解微分方程，并比较：

- 感染人数峰值；
- 峰值出现时间；
- 最终感染人数；
- 疫情持续时间；
- 基本再生数的变化。

## 第七部分 灵敏度、鲁棒性、评估与论文落地
### 14. 灵敏度、情景与鲁棒性分析

灵敏度分析通过主动改变模型中的关键输入，重新运行完整模型，判断结论对参数、数据和假设变化是否稳定。它不是独立模型，而是模型验证的一部分。

灵敏度分析主要回答：

1. 哪些参数对结果影响最大；
2. 参数在合理范围内变化时，目标值、排名、预测或最优方案是否改变；
3. 模型在哪个范围内稳定；
4. 是否存在使方案突然切换的临界值；
5. 某项模型假设失效后，核心结论是否仍然成立。

#### 14.1 统一实施步骤

##### Step 1：建立基准结果

使用原始数据和基准参数运行模型，记录：

- 基准参数 $p_i^0$；
- 基准目标值或输出 $Y^0$；
- 基准最优方案 $x^0$；
- 基准排名、等级、路径、峰值或预测误差；
- 所有约束的满足情况。

后续扰动结果都应与同一个基准模型比较。

##### Step 2：选择关键参数

优先分析：

- 题目没有直接给出、需要估计的参数；
- 来自模型假设、文献或专家判断的参数；
- 存在测量误差或未来波动的输入；
- 目标函数中的权重和风险厌恶系数；
- 容量、时间、资源、需求等关键约束上限；
- 传播率、恢复率、热传导率、增长率等机理参数；
- 可能导致方案切换的成本、价格或阈值。

算法参数与模型参数应分开：交叉率、变异率、种群规模等用于检验求解算法的稳定性；需求量、成本、传播率等用于检验现实模型的稳定性。

##### Step 3：确定扰动范围

单因素相对扰动可写为：

$$
p_i=p_i^0(1+\delta),
$$

其中，$\delta$ 可从 $-20\%$ 到 $20\%$ 取若干值。资料中的 $\pm10\%$ 和 $\pm20\%$ 只是示例，不能作为所有题目的固定标准。实际范围应来自：

- 历史数据波动；
- 测量误差或参数置信区间；
- 物理允许范围；
- 行业标准和业务容差；
- 相关文献；
- 题目明确给出的上下界。

若基准参数接近零，百分比变化没有意义，应设置绝对扰动量或直接给出若干可解释的参数值。

##### Step 4：重新运行完整模型

每个参数变化后，都应重新执行数据处理、模型计算或优化求解。不能只将新参数代入最终结果公式。每次运行至少记录：

- 目标函数或模型输出；
- 决策变量和方案结构；
- 排名或等级；
- 约束违反量与可行性；
- 误差指标；
- 运行时间。

##### Step 5：量化变化程度

局部相对灵敏度可定义为：

$$
S_i=\frac{\Delta Y/Y^0}{\Delta p_i/p_i^0}.
$$

若参数增加 $10\%$、结果增加 $2\%$，则 $S_i=0.2$。$|S_i|$ 越大，结果对该参数越敏感；$S_i$ 的正负表示影响方向。

不能机械规定统一的敏感性阈值。是否可接受应根据题目允许误差、决策容差和方案是否改变判断。对于离散优化，即使目标值变化很小，只要最优方案发生大幅切换，也不能简单认定模型稳定。

##### Step 6：形成稳定性结论

最终应说明：

- 最敏感和最不敏感的参数；
- 影响方向；
- 稳定区间；
- 方案切换或结论失效的临界点；
- 模型在实际误差范围内是否仍可使用。

#### 14.2 单因素灵敏度分析（OAT）

每次只改变一个参数，其余参数保持基准值不变。例如：

$$
\delta\in\{-20\%,-10\%,-5\%,0,5\%,10\%,20\%\}.
$$

适合参数较少、需要清楚解释单个参数作用的赛题，是国赛论文中最常见的方法。

- **优点**：简单、直观、容易解释；
- **缺点**：无法识别参数之间的交互作用；
- **推荐图**：参数—结果折线图、龙卷风图；
- **推荐表**：参数值、目标值、变化率、方案是否改变。

#### 14.3 双因素与多因素分析

当两个参数可能同时变化时，在二维网格上重新求解。例如同时改变价格 $c$ 与需求量 $d$：

$$
c\in[c_{\min},c_{\max}],\qquad d\in[d_{\min},d_{\max}].
$$

适合成本—需求、风险权重—收益权重、温度—材料参数等具有交互作用的情况。

- **推荐图**：热力图、等高线图、三维响应面；
- **重点结论**：稳定区域、极值区域、约束失效区和方案切换边界。

#### 14.9 情景分析与压力测试

当参数之间可能一起变化，但难以确定联合概率分布时，可以设计具有现实含义的情景：

| 情景 | 需求 | 成本 | 风险或环境条件 |
|---|---|---|---|
| 乐观 | 高 | 低 | 有利 |
| 基准 | 中 | 中 | 正常 |
| 悲观 | 低 | 高 | 不利 |
| 压力 | 极低/极高 | 极高 | 最恶劣允许条件 |

每个情景都应重新运行模型，比较目标值、方案结构、约束满足情况和安全裕度。压力测试用于识别模型在哪些极端条件下失效，不要求该情景具有较高发生概率。

#### 14.10 输入噪声与鲁棒性检验

对测量数据或输入数据加入合理扰动：

$$
x_i'=x_i(1+\varepsilon_i),
$$

其中 $\varepsilon_i$ 可服从给定分布，也可在指定区间内取值。资料以增加约 $10\%$ 噪声作为示例，真实噪声范围必须来自测量误差或数据质量分析。

重新运行数据处理、拟合和求解，比较：

- 参数估计偏差；
- 预测或优化结果偏差；
- 排名或分类变化；
- 约束满足率；
- 多次扰动结果的均值和标准差。

更换求解算法后得到相近结果，只能说明数值求解对算法选择可能不敏感，不能单独证明模型对输入噪声、参数变化或分布偏移具有鲁棒性。

#### 14.11 蒙特卡洛灵敏度分析

当多个参数具有概率分布时，可进行随机抽样：

1. 为每个不确定参数确定分布和范围；
2. 随机生成参数样本；
3. 对每组样本运行完整模型；
4. 统计输出的均值、标准差、分位数和超限概率；
5. 计算参数与输出之间的相关关系或重要性。

推荐报告：

$$
E[Y],\quad \operatorname{Std}(Y),\quad Q_{0.05},\quad Q_{0.95},\quad P(Y>Y_{\mathrm{limit}}).
$$

推荐图为输出直方图、箱线图、累计分布曲线和参数—输出散点图。资料中的热防护示例同时改变环境温度和热传导率，并用最恶劣情景检查安全裕度。

#### 14.12 Morris筛选法

当参数较多、逐个精细分析成本过高时，可以先用Morris法筛选重要参数。该方法在参数空间中进行多条随机轨迹，计算每个参数的基本效应。

常用统计量包括：

- $\mu_i^*$：参数总体影响强度；
- $\sigma_i$：参数非线性效应或与其他参数的交互程度。

$\mu_i^*$ 较大表示参数重要，$\sigma_i$ 较大表示影响可能具有非线性或交互。推荐图为 $\mu^*$—$\sigma$ 散点图。Morris适合筛选，不负责精确分解方差贡献。

#### 14.13 Sobol全局灵敏度分析

当模型具有明显非线性和参数交互，并且计算预算允许时，可使用Sobol方差分解。一阶灵敏度指数为：

$$
S_i=\frac{\operatorname{Var}_{X_i}\left(E[Y\mid X_i]\right)}{\operatorname{Var}(Y)}.
$$

总效应指数 $S_{T_i}$ 同时包含参数自身影响以及与其他参数的交互影响。

- $S_i$ 大：参数的独立贡献较强；
- $S_{T_i}-S_i$ 大：该参数与其他参数存在明显交互；
- 多个指数共同解释输出方差来源。

推荐图为一阶指数和总效应指数并列柱状图。Sobol需要较多模型计算，复杂仿真模型可先用Morris筛选，再对少量关键参数使用Sobol。

#### 14.14 不同模型的推荐方案

| 模型类型 | 优先分析参数 | 推荐方法 | 主要观察结果 |
|---|---|---|---|
| 线性规划 | 目标系数、资源上限 | 单因素扰动、影子价格 | 最优值、紧约束、方案切换 |
| 整数/组合优化 | 成本、需求、容量、时间窗 | 情景分析、单/双因素网格 | 目标值、方案结构、可行性 |
| 多目标优化 | 目标权重、风险系数 | 权重扫描、Pareto分析 | 折中方案和前沿变化 |
| AHP/TOPSIS | 指标权重 | 权重扰动 | 得分、第一名和排名稳定性 |
| 回归与机器学习 | 样本、特征、正则参数 | 重采样、噪声扰动 | 系数方向、样本外误差 |
| ARIMA | 训练窗口、阶数、异常数据 | 滚动回测、数据扰动 | 预测值和样本外误差 |
| GM(1,1) | 初始数据、背景值系数 | 数据扰动、滚动建模 | 预测曲线和相对误差 |
| 聚类 | $K$、距离、`eps`、`min_samples` | 参数扫描、重复抽样 | 分群一致性、轮廓系数 |
| SIR/SEIR | $\beta$、$\gamma$、初始感染人数 | 情景分析、单/双因素分析 | 峰值、峰值时间、累计规模 |
| 复杂机理仿真 | 物理参数、初边值 | Morris、Sobol、蒙特卡洛 | 状态曲线、极值和安全裕度 |
| 启发式算法 | 种群、算子概率、迭代数 | 参数实验和多随机种子运行 | Best、Mean、Std、时间和收敛速度 |

#### 14.15 图表选择

| 分析目的 | 首选图 |
|---|---|
| 单个参数影响方向 | 参数—输出折线图 |
| 比较多个参数的重要性 | 龙卷风图 |
| 两参数交互 | 热力图或等高线图 |
| 随机输入导致的输出分布 | 直方图、箱线图或累计分布图 |
| 评价模型排名稳定性 | 排名变化图或权重—排名热力图 |
| 机理参数改变后的动态过程 | 多情景状态曲线 |
| 全局灵敏度贡献 | Sobol指数柱状图 |
| 多参数初筛 | Morris $\mu^*$—$\sigma$ 图 |

每个主模型通常保留一张参数影响图和一张结果稳定性图即可。连续两张图必须分别承担不同证据作用。

#### 14.16 论文写作模板

灵敏度分析段落应包含“扰动依据—重新求解—量化变化—稳定区间—实际解释”。可按下面结构写：

> 为检验模型对参数 $p$ 估计误差的敏感程度，根据其历史波动范围，将 $p$ 在基准值附近按给定区间调整，并在每个参数水平下重新求解完整模型。结果显示，当 $p$ 位于某范围时，目标值变化不超过某比例，且最优方案/前若干名排序保持不变；当 $p$ 超过某临界值后，方案由A切换为B。由此可知，模型在实际允许误差范围内具有稳定性，但应重点关注参数 $p$ 的估计精度。

“显著、稳定、合理、鲁棒”等判断必须紧跟数值、排名变化、误差、可行率或情景对比证据。摘要中若提到灵敏度分析，数字必须能在正文和计算输出中找到对应来源。

#### 14.17 常见错误

1. 对所有参数机械使用 $\pm10\%$ 或 $\pm20\%$；
2. 改变参数后没有重新运行完整模型；
3. 只观察目标值，不检查方案结构、排名和约束；
4. 只展示一个有利情景，不报告不利或极端情景；
5. 将算法超参数变化等同于现实模型稳定性；
6. 将更换算法得到相近结果当作完整鲁棒性证明；
7. 只画图，不报告数值变化和稳定区间；
8. 离散方案发生切换后仍以目标值变化小为由宣称稳定；
9. 蒙特卡洛参数分布没有数据或文献依据；
10. 灵敏度分析在模型完成后临时拼接，与假设和不确定性来源无关。

### 15. 评估指标与图形选择

评价模型时不能只看算法内部指标。完整证据应当同时覆盖三层：

1. **计算层**：算法是否收敛、是否稳定、是否在合理时间内完成；
2. **模型层**：预测误差、分类能力、排序稳定性或拟合程度是否可靠；
3. **问题层**：最终方案是否真正改善成本、收益、距离、服务率等题目指标。

图形按“过程证据—结果证据—验证证据”选择。一般每个主模型保留 2—4 张关键图即可，不为了丰富版面重复展示同一结论。

#### 15.7 题目业务指标必须单独报告

算法指标只说明“计算过程是否可靠”，题目指标才说明“方案是否有用”。不同问题应增加对应业务指标，例如：

- 路径问题：总里程、车辆数、准时率、载重利用率；
- 调度问题：最大完工时间、平均等待时间、延期任务数、设备利用率；
- 种植或生产问题：利润、产量、土地/设备利用率、供需满足率；
- 选址问题：建设成本、覆盖率、平均服务距离、最差服务距离；
- 评价问题：排名、等级、排序稳定性及关键短板指标；
- 传播或控制问题：峰值规模、峰值时间、累计规模和干预成本。

最终论文应形成“算法收敛与稳定—模型误差与有效性—现实方案改善”三层结论，不能只用一条收敛曲线证明整个模型正确。

### 16. 常见误用

1. 线性规划可精确求解，却使用遗传算法制造复杂度；
2. 把 GA、PSO 等求解器当作完整数学模型，不写目标函数和约束；
3. 只展示最好的一次运行，不报告随机性和稳定性；
4. 用罚函数处理约束，却不说明惩罚系数；
5. 不提供简单基线或小规模精确解，无法判断结果质量；
6. 聚类前不标准化，导致大尺度特征支配距离；
7. 时间序列随机划分训练集，造成未来信息泄漏；
8. AHP 不做一致性检验，熵权法不检查异常值；
9. 把相关性、特征重要性或 SHAP 值直接解释为因果效应；
10. 为了显得创新堆叠多个算法，却没有说明每个算法解决了什么缺陷。

### 17. 论文中的标准说明框架

每个主模型或算法建议按照下面的证据链写作：

> 现实对象 → 数学抽象 → 变量和参数 → 基础关系 → 目标与约束/方程 → 闭合假设 → 求解算法 → 参数和停止条件 → 验证方法 → 结果及解释。

若使用改进算法，应再增加：

> 基础算法的具体缺陷 → 新增算子或机制 → 改变的搜索过程 → 公平对照实验 → 改进带来的量化效果。

### 18. 一页式选型结论

- 有明确线性目标和约束：LP；
- 有整数数量或 0-1 选择：IP/MILP；
- 非线性但可求梯度：优先成熟非线性优化器；
- 连续非凸、不可导：DE/PSO/GA；
- 离散排列与路径：先设计贪心和局部搜索，再考虑 ACO、TS、VNS；
- 大规模复杂路径与调度：ALNS；
- 多目标冲突：ε-约束、加权法或 NSGA-II；
- 多指标排序：AHP/熵权法 + TOPSIS；
- 模糊等级：模糊综合评价；
- 少量单调时序：GM(1,1)；
- 较长单变量时序：ARIMA；
- 有标签分类：逻辑回归基线，再与 SVM、随机森林等比较；
- 无标签分群：K-means、层次聚类或 DBSCAN；
- 连续动态过程：微分方程；
- 宏观反馈系统：系统动力学。

最终选择不由模型“高级程度”决定，而由题目结构、数据条件、可解释性、求解规模和验证证据共同决定。
