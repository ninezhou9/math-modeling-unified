# 预测与时序分析

## 多元线性回归 (Multiple Linear Regression)

### 适用性
因变量与多个连续或离散自变量呈线性相关关系，样本量充足且特征间无严重共线性；宏观经济指标、工业参数影响评估。
### 结构或公式
$$y = X\beta + \epsilon, \quad \hat{\beta} = (X^T X)^{-1} X^T y, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I)$$
### 算法专属步骤
1. **数据清洗与相关性探索**：绘制散点图矩阵，计算 Pearson/Spearman 矩阵初筛特征；
2. **矩阵解析求解**：构建设计矩阵 $X$（含常数项列），利用最小二乘法 (OLS) 求解无偏估计量 $\hat{\beta}$；
3. **方差分析与显著性检验**：
   - 全局 $F$ 检验：$F = \frac{SSR / k}{SSE / (n - k - 1)} \sim F(k, n - k - 1)$；
   - 单变量 $t$ 检验：$t_j = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)} \sim t(n - k - 1)$；
4. **残差诊断与模型修正**：检验残差正态性、异方差性（Breusch-Pagan 检验）及自相关性（Durbin-Watson 检验）。
### 约束处理
参数非负或范围约束时，转换为有界最小二乘 (BVLS) 或凸二次规划求解。
### 参数
显著性检验阈值 $\alpha = 0.05$、方差膨胀因子判定阈值 $\text{VIF} < 10$。
### 验证
拟合优度 $R^2$ 与调整 $R_{adj}^2$、交叉验证均方误差 (CV-MSE)、残差 Q-Q 图正态性。
### 风险
多重共线性导致 $(X^T X)$ 接近奇异、参数方差剧烈膨胀且符号反常；内生性问题导致估计偏误。
### 场景
国赛 CUMCM 碳排放影响因素量化、商品定价敏感度分析、能耗回归预测。
### 比较
可解释性极强，具备成熟的统计推断理论；但无法直接捕捉高度非线性与复杂交叉项。

## 多项式回归 (Polynomial Regression)

### 适用性
自变量与因变量呈现明显的单峰、单谷或 S 形非线性曲线趋势，且物理机理支持光滑多项式近似。
### 结构或公式
$$y = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_d x^d + \epsilon, \quad y = V(x)\beta + \epsilon$$
其中 $V(x)$ 为 Vandermonde 矩阵。
### 算法专属步骤
1. **非线性形态辨识**：绘制因变量随自变量变化的二维散点图，观察曲率变化点；
2. **特征多项式升维**：将低维特征 $x$ 映射为 $[x, x^2, \dots, x^d]$ 高维特征空间；
3. **中心化与标准化**：对各高维幂次项进行 Z-score 标准化，消除高次幂带来的量纲失衡与数值不稳定；
4. **OLS/正交多项式求解**：利用正交多项式变换解耦各阶系数，最小化平方残差；
5. **阶数截断与残差分析**：通过递增 $d$ 观察残差平方和下降梯度，确定最优截止阶数。
### 约束处理
物理单调性约束（要求一阶导数 $P'(x) \ge 0$）可转化为半正定规划 (SDP) 或惩罚回归。
### 参数
多项式阶数 $d$（工程建模中通常建议 $d \le 4$）。
### 验证
留一法交叉验证 (LOOCV)、赤池信息准则 (AIC) 与贝叶斯信息准则 (BIC)。
### 风险
龙格现象（Runge's phenomenon）——高阶多项式在区间边缘外推时发生剧烈发散震荡；特征间高共线性。
### 场景
材料力学拉伸应力-应变曲线拟合、化学反应动力学转化率随温度变化曲线。
### 比较
数学形式简单，极易解析求导与极值分析；但在区间外推能力上显著弱于样条回归 (Spline)。

## 岭回归与LASSO (Ridge & LASSO Regression)

### 适用性
特征维度高（甚至 $p > n$）、变量间存在严重多重共线性，或需要筛选核心稀疏特征的回归场景。
### 结构或公式
- **Ridge (L2)**: $\min_{\beta} \|y - X\beta\|_2^2 + \lambda \|\beta\|_2^2 \Rightarrow \hat{\beta}_{Ridge} = (X^T X + \lambda I)^{-1} X^T y$
- **LASSO (L1)**: $\min_{\beta} \frac{1}{2n}\|y - X\beta\|_2^2 + \lambda \|\beta\|_1$
### 算法专属步骤
1. **数据标准化**：对所有自变量去均值并归一化为单位方差（截距项 $\beta_0$ 不参与正则化）；
2. **正则化路径生成**：设定对数等差分布的惩罚参数序列 $\lambda \in [10^{-4}, 10^4]$；
3. **优化求解**：
   - Ridge：直接矩阵代数求逆（$\lambda I$ 保证可逆）；
   - LASSO：采用坐标下降法 (Coordinate Descent) 或软阈值算子 (Soft-thresholding) 迭代更新；
4. **最优参数锁定**：基于 K 折交叉验证均方误差曲线选择最优惩罚系数 $\lambda$。
### 约束处理
L1 范数等价于将参数约束在多维菱形区域内，产生稀疏角点解；L2 范数约束在多维球体内。
### 参数
正则化强度 $\lambda$（或 `alpha`）、ElasticNet 混合比例 $l_1\_ratio \in [0, 1]$。
### 验证
K 折交叉验证（`cv=5` 或 `10`）绘制 MSE 均值及标准误曲线，选取 1-SE 准则点或最小 MSE 点。
### 风险
$\lambda$ 选取过大导致参数过度收缩造成严重欠拟合；强相关特征组 LASSO 倾向于随机保留其一而丢弃其余。
### 场景
基因表达谱与表型预测、宏观经济数十种指标关键影响因子筛选、传感器阵列校准。
### 比较
Ridge 稳定压缩系数保留全部变量；LASSO 兼具特征选择功能；ElasticNet 融合两者应对群组共线性。

## 灰色预测GM(1,1) (Grey System GM(1,1))

### 适用性
数据量极少（$n \ge 4$）、信息贫乏、具有近似单调指数增长/衰减趋势的非负时间序列。
### 结构或公式
- 1-AGO 累加序列：$x^{(1)}(k) = \sum_{i=1}^k x^{(0)}(i)$
- 白化微分方程：$\frac{d x^{(1)}}{dt} + a x^{(1)} = b$
- 时间响应函数：$\hat{x}^{(1)}(k+1) = \left(x^{(0)}(1) - \frac{b}{a}\right) e^{-a k} + \frac{b}{a}$
- 累减还原序列：$\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k)$
### 算法专属步骤
1. **级比检验与可行性判断**：计算级比 $\sigma(k) = \frac{x^{(0)}(k-1)}{x^{(0)}(k)}$，确认是否落入容许区间 $(e^{-\frac{2}{n+1}}, e^{\frac{2}{n+1}})$；
2. **一阶累加生成 (1-AGO)**：对原始非负序列 $x^{(0)}$ 累加生成单调递增序列 $x^{(1)}$ 以弱化随机噪声；
3. **构造紧邻均值矩阵与常数向量**：$z^{(1)}(k) = 0.5 x^{(1)}(k) + 0.5 x^{(1)}(k-1)$，构建数据矩阵 $B$ 与常数项 $Y$；
4. **最小二乘辨识参数**：$\hat{u} = [a, b]^T = (B^T B)^{-1} B^T Y$；
5. **预测还原与精度检验**：计算时间响应序列，累减还原并开展后验差与残差检验。
### 约束处理
当级比不满足要求时，采用平移变换 $y^{(0)}(k) = x^{(0)}(k) + C$ 修正级比后再建模。
### 参数
发展系数 $a$（要求 $|a| < 0.3$ 模型精度高，$|a| > 2$ 时不可使用）、灰色作用量 $b$。
### 验证
残差相对误差检验（平均相对误差 $< 10\%$ 为合格）、后验差比 $C = S_2 / S_1 < 0.35$、小误差概率 $P > 0.95$。
### 风险
严禁用于非单调、强周期波动或含负值的数据序列；中长期外推误差呈指数级剧烈发散。
### 场景
新产品上市初期销量预测、矿山沉降短程趋势预警、罕见病年度发病趋势。
### 比较
少样本（4~10个点）下的首选机理预测工具；但在大数据量与复杂波动下表现远逊于 ARIMA 与时序深度学习。

## ARIMA (自回归差分移动平均模型)

### 适用性
等时间间隔采集的单变量连续时间序列；具备平稳性或经差分后平稳，含自相关或趋势特征。
### 结构或公式
$$\Phi(B)(1-B)^d X_t = c + \Theta(B)\epsilon_t, \quad \left(1 - \sum_{i=1}^p \phi_i B^i\right)(1-B)^d X_t = c + \left(1 + \sum_{j=1}^q \theta_j B^j\right)\epsilon_t$$
其中 $B$ 为滞后算子，$\epsilon_t \sim WN(0, \sigma^2)$。
### 算法专属步骤
1. **平稳性检验 (ADF)**：对原序列进行 Augmented Dickey-Fuller 单位根检验，若不平稳则进行 $d$ 阶差分；
2. **模型定阶 (p, q)**：观察自相关函数 (ACF) 与偏自相关函数 (PACF) 截尾/拖尾特征，或通过网格搜索最小化 AIC/BIC 定阶；
3. **参数估计**：利用极大似然估计 (MLE) 或条件最小二乘法联合估计自回归系数 $\phi$ 与移动平均系数 $\theta$；
4. **残差白噪声检验 (Ljung-Box)**：检验模型残差序列是否为独立无自相关的白噪声；
5. **多步递推预测**：基于差分逆变换还原预测值，并计算各前瞻步长的置信区间。
### 约束处理
模型稳定性约束（AR 多项式的所有特征根均位于单位圆外部）与可逆性约束（MA 特征根位于单位圆外部）。
### 参数
自回归阶数 $p$、差分阶数 $d$（一般 $d \le 2$）、移动平均阶数 $q$、季节周期参数 $(P, D, Q)_s$。
### 验证
残差 Ljung-Box 检验 $p\text{-value} > 0.05$（无自相关）、滚动前瞻交叉验证 (Rolling Window CV)、MAPE 与 RMSE。
### 风险
过度差分（$d \ge 3$）导致有效信息彻底丢失并引入人工负相关；无法捕捉结构突变与外部协变量影响。
### 场景
气象日均温度预测、电力系统短期负荷预测、电商日访问量走势预报。
### 比较
经典线性时序分析的黄金标准；相较于机器学习模型无需复杂特征工程，但无法建模非线性动力学。

## 线性混合效应模型 (LMM, Linear Mixed Models)

### 适用性
具有分层/分组嵌套结构、重复测量或面板数据 (Panel Data)；处理组内相关性与个体异质性。
### 结构或公式
$$y = X\beta + Z u + \epsilon, \quad u \sim \mathcal{N}(0, G), \quad \epsilon \sim \mathcal{N}(0, R)$$
其中 $\beta$ 为固定效应系数，$u$ 为随机效应向量。
### 算法专属步骤
1. **层级结构定义**：划分固定效应矩阵 $X$（群体平均规律）与随机效应设计矩阵 $Z$（组别/个体差异）；
2. **协方差结构设定**：指定随机效应方差矩阵 $G$（如非结构化、对角结构）与残差矩阵 $R$；
3. **受限极大似然估计 (REML)**：利用 REML 消除固定效应引起的自由度损失，估计方差分量；
4. **广义最小二乘求解**：基于估计的协方差更新固定效应 $\hat{\beta} = (X^T V^{-1} X)^{-1} X^T V^{-1} y$；
5. **最佳线性无偏预测 (BLUP)**：计算各群组独特的随机效应向量 $\hat{u} = G Z^T V^{-1} (y - X\hat{\beta})$。
### 约束处理
随机效应协方差矩阵 $G$ 必须满足对称半正定约束，通过 Cholesky 因子分解参数化求解。
### 参数
固定效应项、随机截距/随机斜率结构、优化收敛容差。
### 验证
似然比检验 (LRT) 评估随机效应显著性、组内相关系数 (ICC)、条件拟合优度 $R_{cond}^2$ 与边际拟合优度 $R_{marg}^2$。
### 风险
分组数目过少（组数 $<5$）导致随机效应方差估计奇异退化为 0；模型过度复杂导致梯度奇异。
### 场景
多试验田多年农作物产量追踪、不同医院患者术后指标纵向随访、不同学校学生学业成长轨迹分析。
### 比较
相比普通 OLS 解决了样本非独立问题；相比固定效应哑变量模型，具备更强的跨群体泛化与降维收缩能力。

## 组合预测 (Combined Forecasting)

### 适用性
单一模型预测存在视角局限与偏差，需整合多个异构基模型（统计模型、机理模型、机器学习）以增强鲁棒性。
### 结构或公式
$$\hat{y}_t = \sum_{i=1}^m w_i \hat{y}_{it} \quad \text{s.t.} \quad \sum_{i=1}^m w_i = 1, \; w_i \ge 0$$
### 算法专属步骤
1. **基模型独立构建**：独立训练 $m$ 个机制互补的基模型（如 ARIMA、GM(1,1)、SVR、LightGBM）；
2. **误差序列提取**：在留出验证集上提取各模型的历史预测误差向量 $e_i = y - \hat{y}_i$；
3. **误差协方差矩阵构建**：计算误差协方差矩阵 $E = [e_{ij}]_{m \times m}$，其中 $e_{ij} = \frac{1}{N}\sum e_{it} e_{jt}$；
4. **组合权重优化求解**：求解方差最小化二次规划：
   $$\min_w w^T E w \quad \text{s.t.} \quad \mathbf{1}^T w = 1, \; w \ge 0$$
   或采用简单倒数方差法 $w_i = \frac{1/\sigma_i^2}{\sum 1/\sigma_k^2}$；
5. **动态加权输出**：根据求得的最优权重向量合成最终预测值。
### 约束处理
非负凸组合约束（$w_i \ge 0, \sum w_i = 1$），避免无界负权重导致预测值超出物理合理域。
### 参数
基模型数量 $m \in [2, 5]$、权重更新滚动滑动窗口长度 $W$。
### 验证
与各独立单模型的 RMSE/MAE 增益对比、Diebold-Mariano (DM) 检验评估精度提升显著性。
### 风险
选入严重劣质基模型拖垮整体性能；当基模型间预测残差强正相关时，组合几乎无法提供方差缩减收益。
### 场景
电网多尺度综合负荷预测、极端天气灾害多气象模式集成预报、多源物价指数集成预测。
### 比较
通过分散单模型建模风险实现方差缩减，鲁棒性极高；但增加了系统的工程计算开销与复杂度。

## 指数平滑 (Exponential Smoothing, Holt-Winters)

### 适用性
包含水平、线性趋势和季节周期的短期时间序列预测；计算速度极快、无需严苛平稳性假设。
### 结构或公式
Holt-Winters 加法模型：
- 水平方程：$L_t = \alpha (y_t - S_{t-m}) + (1-\alpha)(L_{t-1} + b_{t-1})$
- 趋势方程：$b_t = \beta (L_t - L_{t-1}) + (1-\beta) b_{t-1}$
- 季节方程：$S_t = \gamma (y_t - L_{t-1} - b_{t-1}) + (1-\gamma) S_{t-m}$
- 预测公式：$\hat{y}_{t+h} = L_t + h b_t + S_{t+h-m}$
### 算法专属步骤
1. **模型类型选型**：依据季节振幅是否随趋势放大选择加法模型 (Additive) 或乘法模型 (Multiplicative)；
2. **初始状态估计**：利用前几个周期数据均值初始化水平 $L_0$、初始斜率 $b_0$ 与季节因子向量 $S_{-m..0}$；
3. **参数极大似然/误差最小化**：利用 L-BFGS-B 或 Nelder-Mead 优化平滑参数 $(\alpha, \beta, \gamma)$ 最小化单步预测误差平方和 (SSE)；
4. **递推更新与前瞻预测**：按时序逐点更新状态分量，生成未来 $h$ 步前瞻预测与预测区间。
### 约束处理
平滑系数严格约束在 $(0, 1)$ 内，保证近期观测具有更高衰减权重。
### 参数
水平系数 $\alpha \in (0, 1)$、趋势系数 $\beta \in (0, 1)$、季节系数 $\gamma \in (0, 1)$、周期长度 $m$、阻尼系数 $\phi \in (0, 1]$。
### 验证
残差正态性与自相关检验、滚动多步交叉验证 (Rolling Multi-step CV)、MAE/MAPE。
### 风险
乘法季节模型对序列中的零值或负值极度敏感；无阻尼趋势在中远期外推时会产生过度线性发散。
### 场景
连锁超市商品月度销售预测、交通枢纽季度客运周转量预测、服务器内存占用率短期平滑。
### 比较
相较于 ARIMA 无需复杂的差分定阶操作，参数物理直观、计算耗时极低，中短期预测精度高度稳健。
