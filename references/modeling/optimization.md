# 优化决策与运筹求解

## 线性规划 (LP)

### 适用性
目标函数与所有约束条件均为连续决策变量的严格线性函数；适用于生产计划、资源配给、下料与静态物流调度。
### 结构或公式
$$\min_{x} c^T x \quad \text{s.t.} \quad A x \le b, \; A_{eq} x = b_{eq}, \; l \le x \le u$$
### 算法专属步骤
1. **基可行解初始化**：构建标准型并构造初始基变量矩阵 $B$；
2. **最优性检验**：计算各非基变量检验数 $\sigma_j = c_j - c_B^T B^{-1} P_j$；
3. **进基与出基**：若存在 $\sigma_j < 0$，选最小者为进基变量，按最小比值原则 $\theta = \min \{ (B^{-1}b)_i / y_{ik} \mid y_{ik} > 0 \}$ 确定出基变量；
4. **枢轴旋转变换**：高斯消元更新单纯形表，重复迭代直至所有 $\sigma_j \ge 0$。
### 约束处理
不等式引入松弛/剩余变量化为标准型；初始不可行时采用大M法或两阶段单纯形法构造人工变量。
### 参数
求解容差 `tol`（$10^{-7}$）、算法选择（Primal/Dual Simplex 或 Barrier 内点法）。
### 验证
强对偶定理检验（原问题目标值等于对偶目标值）、互补松弛条件校验、影子价格与敏感度分析区间。
### 风险
非线性关系强行线性化造成截断失真；存在退化基导致单纯形法死循环（需启用 Bland 规则）。
### 场景
国赛 CUMCM 资源调配、下料排样、静态供应链流分配。
### 比较
具有多项式可解性（内点法），求解速度极快，但无法处理离散步长与逻辑互斥决策。

## 整数规划与混合整数规划 (IP/MILP)

### 适用性
决策变量部分或全部受限于整数/离散取值，目标与约束为线性；选址定点、航班机组排班、机组组合。
### 结构或公式
$$\min_{x, y} c^T x + d^T y \quad \text{s.t.} \quad A x + B y \le b, \; x \ge 0, \; y \in \mathbb{Z}^p$$
### 算法专属步骤
1. **连续松弛求解**：忽略整数约束，求解连续 LP 松弛问题得到最优解 $(\hat{x}, \hat{y})$；
2. **分支定界**：若 $\hat{y}_j \notin \mathbb{Z}$，创建两个子节点分别增加约束 $y_j \le \lfloor \hat{y}_j \rfloor$ 与 $y_j \ge \lceil \hat{y}_j \rceil$；
3. **割平面增强**：在节点处生成 Gomory 割、MIR 割等有效不等式紧缩松弛多面体；
4. **剪枝与界更新**：子问题不可行、目标劣于已知整数可行解上界、或得到更优整数解时更新全局界并剪枝。
### 约束处理
大M法线性化逻辑条件（如 $y=1 \Rightarrow a^T x \le b$ 转化为 $a^T x - b \le M(1-y)$）；分段线性函数 Special Ordered Sets (SOS2)。
### 参数
相对最优间隙 `MIPGap`（$10^{-4}$ 或 $0.1\%$）、时间限制 `TimeLimit`、启发式搜索频率 `Heuristics`。
### 验证
检查最优解的整数满足度、Upper Bound 与 Lower Bound 收敛曲线、Gap 值变化。
### 风险
大M参数设定过大导致数值病态/数值击穿，设定过小误剪可行解；大规模 NP-hard 问题搜索树爆炸。
### 场景
复杂设施选址-分配、列车运行图编制、生产车间批量计划。
### 比较
相较启发式算法具备严格的最优性证明与理论界保证；较纯 LP 计算复杂度呈指数级上升。

## 0-1规划 (0-1 Programming)

### 适用性
决策变量仅取值 0 或 1 的纯离散选择问题；多项目投资组合、背包问题、互斥路径选择。
### 结构或公式
$$\max_{x} \sum_{j=1}^n c_j x_j \quad \text{s.t.} \quad \sum_{j=1}^n a_{ij} x_j \le b_i \; (i=1..m), \quad x_j \in \{0, 1\}$$
### 算法专属步骤
1. **预处理与探测**：基于变量界与行逻辑做团合并（Clique Merging）与系数紧缩；
2. **隐枚举/伪布尔优化**：按目标收益率降序排序变量，计算部分定值向量的理论目标上界；
3. **冲突驱动学习**：构建冲突图（Conflict Graph），在分支失败时学习不可行割集；
4. **回溯搜索**：穷举所有可能组合中无法剪枝的分支直到最优。
### 约束处理
互斥约束（$\sum x_j \le 1$）、依赖前置约束（$x_k \le x_j$）、精确选择约束（$\sum x_j = K$）。
### 参数
分支优先级变量指定、割平面生成激进度（Cuts 参数）。
### 验证
枚举可行子集检验、目标函数系数扰动灵敏度分析。
### 风险
松弛多面体定界过松导致遍历节点数激增；错误表达非线性逻辑导致约束失效。
### 场景
应急物资储备库选址、投资组合决策、生产线设备启停计划。
### 比较
MILP 的重要特例，主流商业求解器包含专门针对 0-1 变量的 Clique Cut 与 Probing 优化。

## 非线性规划 (NLP)

### 适用性
目标函数或约束中含有平方、幂函数、指数或三角函数等非线性项；工程结构受力、轨迹控制、参数拟合。
### 结构或公式
$$\min_{x} f(x) \quad \text{s.t.} \quad g_i(x) \le 0 \; (i=1..m), \quad h_j(x) = 0 \; (j=1..p), \quad x \in \mathbb{R}^n$$
### 算法专属步骤
1. **构造拉格朗日函数**：$L(x, \lambda, \mu) = f(x) + \sum \lambda_i g_i(x) + \sum \mu_j h_j(x)$；
2. **KKT 系统线性化 (SQP)**：在当前点展开二阶泰勒近似，构建二次规划子问题 (QP) 求解搜索方向 $d_k$；
3. **线搜索确定步长**：采用 Armijo/Wolfe 准则评估价值函数以确保充分下降；
4. **拟牛顿更新**：利用 BFGS 公式更新拉格朗日 Hessian 矩阵估计 $B_{k+1}$ 并迭代。
### 约束处理
序列二次规划法 (SQP)、内点惩罚障碍法 (IPOPT)、增广拉格朗日乘子法。
### 参数
收敛容差 `ftol`/`gtol`（$10^{-6}$）、最大迭代步数 `max_iter`、线搜索回溯系数 $\beta \in (0.1, 0.8)$。
### 验证
KKT 一阶导数范数 $\|\nabla L\| \le \epsilon$、二阶充分条件检验、多初始点（Multi-start）排除局部极小。
### 风险
非凸非线性问题极易陷入局部极值；初值选在奇异点或不可行域导致 Hessian 奇异或发散。
### 场景
飞行器再入轨道优化、化工厂反应器物料与能耗平衡、电力潮流计算。
### 比较
若为凸优化问题局部最优即全局最优；相较于元启发式算法，具有二阶收敛速度与极高精度。

## 多目标规划 (Multi-Objective Optimization)

### 适用性
系统中存在多个相互冲突且不可公度的目标函数；成本-效益折中、质量-工期平衡。
### 结构或公式
$$\min_{x \in \Omega} F(x) = [f_1(x), f_2(x), \dots, f_k(x)]^T$$
### 算法专属步骤
1. **理想点与底点测定**：分别单目标求解各 $f_i(x)$ 确定理想解 $f_i^*$ 与底点 $f_i^{nad}$；
2. **标量化转换**：
   - 加权综合法：$\min \sum_{i=1}^k w_i \frac{f_i(x) - f_i^*}{f_i^{nad} - f_i^*}$，其中 $\sum w_i = 1$；
   - $\epsilon$-约束法：$\min f_1(x)$ s.t. $f_i(x) \le \epsilon_i \; (\forall i \ge 2)$；
3. **前沿采样**：在权重空间或 $\epsilon$ 网格内系统遍历，调用求解器生成非劣解集；
4. **Pareto 前沿构造**：剔除被支配解，保留非劣解点云。
### 约束处理
将 $k-1$ 个目标转化为带弹性裕度的约束条件（$\epsilon$-约束法）。
### 参数
目标权重向量 $w$、$\epsilon$ 步长网格密度、目标归一化上下界。
### 验证
Pareto 非支配性检验、超体积指标 (Hypervolume, HV)、前沿分布均匀度指标 (Spacing)。
### 风险
线性加权法在非凸 Pareto 前沿的凹陷区域无法获得任何非劣解；权重主观赋予导致前沿分布失真。
### 场景
供应链多级选址（成本最小 vs 响应时延最小）、微电网运行调度（经济性 vs 碳排放）。
### 比较
精确标量化方法适用于凸规划体系；对于强非凸或不可微多目标，需采用 NSGA-II 等演化多目标算法。

## 组合优化 (Combinatorial Optimization)

### 适用性
解空间由有限离散元素的排列、子集划分或图拓扑构成；背包问题、TSP、作业车间调度 (JSP)。
### 结构或公式
$$\min_{S \subseteq E} c(S) \quad \text{s.t.} \quad S \in \mathcal{F} \quad (\mathcal{F} \text{ 为可行独立集族})$$
### 算法专属步骤
1. **结构剖析**：分析问题是否具备拟阵性质、最优子结构或重叠子问题；
2. **动态规划/状态压缩**：构建状态转移方程 $DP(mask, i) = \min_{j} \{ DP(mask \setminus \{i\}, j) + dist(j, i) \}$；
3. **分支限界剪枝**：利用松弛下界（如 1-Tree 距离、连续松弛）进行分支定界；
4. **核心域缩减**：对大规模输入执行候选集过滤（如 KNN 邻接边剪枝）。
### 约束处理
紧致编码映射（排列编码、二进制掩码 bitmask）、不可行解拓扑修复投影。
### 参数
状态缓存上限、剪枝阈值、搜索深度限制。
### 验证
与理论下界（松弛界/拉格朗日松弛对偶界）对比计算相对 Gap、极小规模全排列对比。
### 风险
状态维度灾难（Curse of Dimensionality）；约束强耦合破坏子结构递推特性。
### 场景
复杂车辆路径规划 (VRP)、切削下料排样、网络拓扑生成。
### 比较
小规模问题求得绝对精确最优；中大规模 NP-hard 组合优化需转入元启发式与邻域搜索。

## 遗传算法 (GA)

### 适用性
复杂、非凸、不可微、多峰值的黑箱优化与离散排程优化。
### 结构或公式
个体适应度 $Fit(x) = \frac{1}{1 + f(x)}$；演化操作算子集 $\mathcal{G} = \{Selection, Crossover, Mutation\}$。
### 算法专属步骤
1. **染色体编码与初始化**：生成规模为 $N$ 的初始种群（实数编码或排列编码）；
2. **适应度评估**：计算各染色体目标值与适应度得分；
3. **选择算子**：轮盘赌选择（Roulette Wheel）或二元锦标赛选择（Tournament）；
4. **交叉与变异**：按概率 $P_c$ 执行两点交叉/顺序交叉 (OX)，按概率 $P_m$ 执行交换变异；
5. **精英保留**：将当前代最优的 $K$ 个个体无条件复制到下一代；
6. **终止循环**：达到最大代数 $T_{max}$ 或适应度连续停滞时输出最优解。
### 约束处理
外点自适应罚函数 $f_{pen}(x) = f(x) + \sum \lambda_i [\max(0, g_i(x))]^2$；合法化修复算子。
### 参数
种群规模 $N \in [50, 200]$、交叉概率 $P_c \in [0.7, 0.95]$、变异概率 $P_m \in [0.01, 0.1]$、精英保留数 $K \in [1, 5]$。
### 验证
适应度进化收敛曲线、多独立随机种子（至少10次）统计均值与方差。
### 风险
早熟收敛（陷入局部极值点）；演化后期缺乏爬坡微调能力导致精度不高。
### 场景
柔性车间流水线调度、管网布局参数标定、传感器阵列覆盖优化。
### 比较
具备强大的全局空间探索能力，但精细局部搜索弱于局部搜索/SA；常与局部搜索结合构成模因算法。

## 粒子群优化 (PSO)

### 适用性
连续参数空间中的多峰连续函数寻优、模型参数辨识与神经网络超参数优化。
### 结构或公式
$$v_i^{t+1} = w v_i^t + c_1 r_1 (pbest_i - x_i^t) + c_2 r_2 (gbest - x_i^t), \quad x_i^{t+1} = x_i^t + v_i^{t+1}$$
### 算法专属步骤
1. **种群初始化**：随机生成 $M$ 个粒子的初始位置 $x_i$ 与初始速度 $v_i$；
2. **个体与群体极值更新**：评估适应度，更新个体历史最优 $pbest_i$ 与群体全局最优 $gbest$；
3. **动态权重更新**：采用线性递减权重 $w(t) = w_{max} - \frac{t}{T}(w_{max} - w_{min})$；
4. **状态演化与边界截断**：按公式更新速度与位置，超过边界变量实施截断或反弹；
5. **收敛判断**：达到代数或全局极值增益小于容差时停止。
### 约束处理
边界反弹/吸收机制；Deb 可行性法则（可行解优于不可行解，两不可行解按违规度比较）。
### 参数
粒子数 $M \in [30, 80]$、$w \in [0.4, 0.9]$、$c_1 = c_2 = 1.5 \sim 2.0$、速度上限 $v_{max} = 0.2 (x_{max} - x_{min})$。
### 验证
粒子群空间方差衰减监测、群体适应度标准差演变曲线。
### 风险
高维空间下粒子群极速坍缩聚集于伪极值点；参数 $w$ 过大导致振荡发散。
### 场景
控制系统 PID 增益整定、电力系统无功补偿优化、非线性参数辨识。
### 比较
算法结构极简、调节参数少、连续空间收敛极快；但在复杂离散问题上性能劣于 GA/ACO。

## 模拟退火 (SA)

### 适用性
大规模单目标组合优化与连续优化；擅长跳出局部最优陷阱的单点搜索启发式。
### 结构或公式
Metropolis 接受准则转移概率：
$$P(\Delta E, T_k) = \begin{cases} 1, & \Delta E < 0 \\ \exp\left(-\frac{\Delta E}{T_k}\right), & \Delta E \ge 0 \end{cases}, \quad T_{k+1} = \alpha T_k$$
### 算法专属步骤
1. **初始化**：生成初始解 $x_0$，设定初始高温 $T_0$、终止温度 $T_{end}$ 与马尔可夫链长 $L$；
2. **邻域扰动**：在当前解 $x$ 的邻域内随机产生新候选解 $x'$（如 2-opt、Swap）；
3. **能量差计算与转移**：计算增量 $\Delta E = f(x') - f(x)$，按 Metropolis 准则决定是否接受 $x'$；
4. **内循环平衡**：在同一温度 $T_k$ 下重复扰动评估 $L$ 次；
5. **降温衰减**：按 $T_{k+1} = \alpha T_k$ 降温并记录全局最优解，直到 $T < T_{end}$。
### 约束处理
邻域算子严格构造在可行域内；或在能量函数中加入动态温度惩罚项。
### 参数
初始温度 $T_0$（确保初始接受率 $\approx 85\%$）、降温系数 $\alpha \in [0.90, 0.99]$、链长 $L \in [100, 1000]$。
### 验证
降温过程中能量期望与方差衰减轨迹、独立重复运行收敛一致性。
### 风险
降温过快（$\alpha$ 太小）退化为贪心爬坡陷入局部极小；链长过大导致耗时过长。
### 场景
经典 TSP 求解、集成电路 VLSI 芯片布线、三维装箱排样。
### 比较
内存开销极小（仅维护单个解），理论上以概率 1 渐近收敛到全局最优；缺乏群体协同探索能力。

## NSGA-II (带精英保留的多目标遗传算法)

### 适用性
2~3个冲突目标的多目标非线性与复杂离散优化；直接求解非劣前沿集合。
### 结构或公式
快速非支配分层（$F_1, F_2, \dots$）；拥挤度距离：
$$I_d(i) = \sum_{m=1}^M \frac{f_m(i+1) - f_m(i-1)}{f_m^{max} - f_m^{min}}$$
### 算法专属步骤
1. **种群合并**：将父代种群 $P_t$ 与子代种群 $Q_t$ 合并为规模为 $2N$ 的集合 $R_t$；
2. **快速非支配排序**：计算支配数 $n_p$ 与被支配集合 $S_p$，逐层分级 $F_1, F_2, \dots$；
3. **拥挤度计算与精英截断**：按层级顺序填入新父代 $P_{t+1}$，临界层按拥挤度距离降序截取满 $N$ 个个体；
4. **拥挤度锦标赛选择**：优先选非支配等级低者，同级选拥挤度大者；
5. **演化生成子代**：执行模拟二进制交叉 (SBX) 和多项式变异 (PM) 生成 $Q_{t+1}$。
### 约束处理
约束支配原则（若均违规选违规小者；若一可行一违规选可行者；若均可行按帕累托支配）。
### 参数
种群数 $N \in [100, 200]$、交叉分布指数 $\eta_c = 20$、变异分布指数 $\eta_m = 20$、代数 $T \in [200, 500]$。
### 验证
Pareto 前沿形态、超体积指标 (Hypervolume, HV)、反向代距 (Inverted Generational Distance, IGD)。
### 风险
目标维度 $M > 3$ 时非支配个体比例爆炸，选择压力急剧衰减（高维目标需改用 NSGA-III）。
### 场景
水资源多目标综合调度、电动汽车充电站多准则布局、飞机翼型气动与结构多目标优化。
### 比较
计算复杂度由 $O(M N^3)$ 降至 $O(M N^2)$，免除人工指定共享半径，综合性能优越。

## 蚁群算法 (ACO)

### 适用性
基于图拓扑路径构建的离散组合优化；TSP、车辆路径规划 (VRP)、网络路由。
### 结构或公式
转移概率：
$$P_{ij}^k = \frac{[\tau_{ij}]^\alpha [\eta_{ij}]^\beta}{\sum_{l \in allowed_k} [\tau_{il}]^\alpha [\eta_{il}]^\beta}, \quad \tau_{ij}(t+1) = (1-\rho)\tau_{ij}(t) + \sum_{k=1}^m \Delta \tau_{ij}^k$$
### 算法专属步骤
1. **信息素初始化**：给图中所有边赋予初始微量信息素 $\tau_0$；
2. **蚂蚁路径构建**：$m$ 只蚂蚁根据转移概率与禁忌表（Tabu List）逐步移动完成回路；
3. **启发式信息引导**：结合边权倒数 $\eta_{ij} = 1/d_{ij}$ 增强局部导向；
4. **信息素更新**：全局信息素按挥发率 $\rho$ 衰减，最优蚂蚁（Ant-Cycle模型）在走过路径上沉积信息素 $\Delta \tau = Q/L_k$；
5. **迭代寻优**：清空禁忌表，循环迭代直到收敛。
### 约束处理
禁忌表维护可行邻接点，直接剪除违反容量、时间窗或重复访问的节点。
### 参数
信息素重要度 $\alpha \in [1, 2]$、启发重要度 $\beta \in [2, 5]$、挥发系数 $\rho \in [0.1, 0.5]$、蚂蚁数 $m \approx 1.5 n$。
### 验证
最优路径与平均路径代际收敛曲线、信息素分布熵监控。
### 风险
初期信息素匮乏导致搜索随机盲目；$\rho$ 过小导致早熟停滞，$\rho$ 过大导致历史经验遗忘。
### 场景
冷链物流车辆配送路径优化 (VRPTW)、电信网络动态路由配置。
### 比较
正反馈机制极度契合图上路径搜索；相较于 GA，在 TSP/VRP 等问题上收敛质量更具针对性。

## 禁忌搜索 (TS)

### 适用性
易陷入局部极值的离散排产与组合优化；作业车间调度、二次分配问题 (QAP)。
### 结构或公式
禁忌表 $T = \{move_1, move_2, \dots, move_L\}$；特赦准则：$f(x') < f_{best\_global} \Rightarrow$ 解禁。
### 算法专属步骤
1. **初始解生成**：贪心或启发式生成初始解 $x_{current}$，令 $x_{best} = x_{current}$；
2. **候选邻域生成**：对当前解执行扰动生成候选集 $N(x_{current})$；
3. **禁忌判断与特赦**：评估候选解，筛选非禁忌移动；若某禁忌移动达到全局历史最优则强制特赦；
4. **状态转移与表维护**：选择最优候选解作为新当前解，将该逆向移动入队禁忌表，超时移动出队；
5. **终止检查**：达到最大迭代次数或停滞步数后终止。
### 约束处理
候选解生成时显式过滤非法动作；违规解赋予阶梯高额惩罚值。
### 参数
禁忌长度 $L \in [\sqrt{n}, 2\sqrt{n}]$（固定或动态随机）、候选集采样比例。
### 验证
搜索轨迹多样性度量、全局最优解更新频次与步数间隔统计。
### 风险
禁忌长度过小导致在局部小循环中无限震荡；禁忌长度过大导致可行搜索空间被过度锁死。
### 场景
生产流水线排程、通信频率分配、大型集装箱堆存分配。
### 比较
单点深入探索能力强，内存开销小；对初始解质量与邻域移动算子设计依赖度高。

## 差分进化 (DE)

### 适用性
连续参数空间中的非线性、不可微实数全局优化；动力学参数反演与复杂曲面极值搜索。
### 结构或公式
变异向量 $v_i = x_{r1} + F \cdot (x_{r2} - x_{r3})$；二项式交叉：
$$u_{i,j} = \begin{cases} v_{i,j}, & rand(0, 1) \le CR \text{ 或 } j = j_{rand} \\ x_{i,j}, & \text{otherwise} \end{cases}$$
### 算法专属步骤
1. **种群初始化**：在搜索边界内均匀随机生成实数个体种群 $\{x_i \mid i=1..NP\}$；
2. **差分变异**：随机抽取三个互不相同的个体，计算差分矢量并缩放生成变异向量 $v_i$；
3. **交叉操作**：将原个体 $x_i$ 与变异个体 $v_i$ 进行二项式交叉，生成试验个体 $u_i$；
4. **贪婪选择**：比较 $f(u_i)$ 与 $f(x_i)$，保留更优者进入下一代种群；
5. **迭代终止**：达到最大代数或种群离散度小于阈值时终止。
### 约束处理
边界越界截断或重新映射；约束问题结合自适应罚函数或 Deb 可行优先法则。
### 参数
种群规模 $NP \in [5D, 10D]$、缩放因子 $F \in [0.4, 0.9]$、交叉概率 $CR \in [0.3, 0.9]$。
### 验证
均方根误差衰减曲线、测试函数（如 Rastrigin/Rosenbrock）收敛稳定性。
### 风险
$F$ 设置过小导致种群多样性过快丧失而早熟；高维强关联变量下交叉效率下降。
### 场景
复杂物理动力学微分方程参数拟合、雷达天线阵列方向图综合。
### 比较
变异算子基于种群自身差分分布自适应缩放，连续域寻优稳定性与精度普遍优于标准 GA 与 PSO。

## 变邻域搜索 (VNS)

### 适用性
解空间复杂、易被深层局部极小阻隔的离散组合优化；选址-路径联合优化 (LRP)。
### 结构或公式
预定义一组具有不同扰动尺度的邻域结构集合 $\{\mathcal{N}_1, \mathcal{N}_2, \dots, \mathcal{N}_{k_{max}}\}$。
### 算法专属步骤
1. **初始解与阶数设定**：构造初始可行解 $x$，设定 $k = 1$；
2. **抖动探索 (Shaking)**：从第 $k$ 阶邻域 $\mathcal{N}_k(x)$ 中随机抽取解 $x'$；
3. **局部深入搜索**：以 $x'$ 为初始点，调用确定性局部搜索得到局部极值 $x''$；
4. **移动准则检验**：若 $f(x'') < f(x)$，则接受新解 $x \leftarrow x''$，重置 $k \leftarrow 1$；否则 $k \leftarrow k + 1$；
5. **循环与重置**：若 $k > k_{max}$，重置 $k \leftarrow 1$，直至达到总耗时或迭代上限。
### 约束处理
抖动与局部搜索算子内部保证拓扑合法性，违规解直接舍弃。
### 参数
邻域总数 $k_{max} \in [3, 7]$（如 1-Swap, 2-Opt, Relocate, Cross-Exchange）、局部搜索步数上限。
### 验证
各阶邻域跳出局部极小成功率统计、解的改进阶梯图。
### 风险
局部搜索过于耗时导致抖动循环次数不足；各阶邻域结构同质化无法突破能量壁垒。
### 场景
多车型带时间窗车辆路径问题 (VRPTW)、多目标设施布局问题。
### 比较
机制简洁易实现，通过系统性切换邻域尺度摆脱局部最优；求解质量显著高于单一局部搜索。

## 大邻域搜索 (LNS/ALNS)

### 适用性
超大规模、强约束组合优化（大规模 VRP、列车排班）；求解质量逼近商业求解器。
### 结构或公式
破坏算子集 $\mathcal{D} = \{D_1, \dots, D_p\}$ 与修复算子集 $\mathcal{R} = \{R_1, \dots, R_q\}$；自适应算子权重更新：
$$w_i^{t+1} = (1-\rho)w_i^t + \rho \frac{\pi_i}{\theta_i}$$
### 算法专属步骤
1. **构造初始解**：启发式生成初始可行解 $x$，初始化算子权重；
2. **算子自适应轮盘赌**：依据历史得分权重动态选择一对破坏算子 $D_i$ 与修复算子 $R_j$；
3. **解的破坏与重构**：$D_i$ 移除 $q$ 个元素（随机破坏、Shaw 相似度破坏），$R_j$ 重新插入（贪心插入、Regret-k 插入）获得 $x'$；
4. **解的接受准则**：基于模拟退火接受准则决定是否接受 $x'$ 并更新全局最优；
5. **权重分段奖惩**：根据新解质量（全局更优、当前更优、被接受）分配增量分数 $\pi$，周期性更新权重。
### 约束处理
修复算子插入元素时显式检测容量、时间窗与拓扑约束，剪除非法插入位置。
### 参数
破坏比例 $q \in [10\%, 30\%]$、平滑因子 $\rho \in [0.1, 0.2]$、得分分级 $(\sigma_1=33, \sigma_2=20, \sigma_3=9)$。
### 验证
破坏-修复循环中目标函数演变图、各破坏/修复算子调用频次与得分贡献柱状图。
### 风险
算子实现逻辑复杂；破坏规模 $q$ 过大退化为随机搜索，过小退化为普通局部搜索。
### 场景
大规模即时外卖即时配送路径规划、航空公司机组与机位调度。
### 比较
现代解决大规模 VRP/JSP 的顶级启发式框架；相比标准 GA/ACO 在强约束大尺度问题上具备压倒性搜索效率。

## 贪心算法 (Greedy Algorithm)

### 适用性
具有最优子结构与贪心选择性质的离散结构决策；快速构造初始解、实时流式决策。
### 结构或公式
局部贪心选择策略：
$$x_{k} = \arg\max_{x \in S_k} \text{Utility}(x)$$
### 算法专属步骤
1. **候选集建立**：将待决策元素按局部效用度量（如性价比 $v_i/w_i$、最短距离）建立优先队列；
2. **逐步扩展**：依次从候选集中提取最优元素；
3. **可行性检测**：检查加入当前部分解后是否满足全局约束；
4. **纳入或舍弃**：若可行则并入解集，不可行则永久舍弃；
5. **终止检查**：候选集为空或目标达成时输出结果。
### 约束处理
逐步构建中做强约束过滤，一旦违背直接剪枝。
### 参数
局部启发式评估函数设计（如单位增益比率）。
### 验证
理论最优近似比证明（如 Kruskal 算法精确最优；分数背包精确最优；0-1背包无界保证）。
### 风险
无后效性假设一旦失效，极易过早做出短视选择陷入极差劣解甚至导致无解。
### 场景
最小生成树构造、哈夫曼编码、元启发式算法高质量初始解快速生成。
### 比较
计算复杂度极低（$O(n \log n)$），响应极快；但对大多数 NP-hard 问题无法保证全局最优。

## 局部搜索 (Local Search)

### 适用性
连续或离散优化中快速下沉至局部极小点；元启发式算法内嵌的核心爬坡引擎。
### 结构或公式
邻域空间映射 $N(x) = \{x' \mid \text{dist}(x, x') \le \delta\}$；最速下降迭代：
$$x_{t+1} = \arg\min_{y \in N(x_t)} f(y)$$
### 算法专属步骤
1. **选定初始点**：给定初始解 $x$；
2. **邻域遍历与评估**：在邻域算子（如 2-opt、Swap、Relocate）下生成邻域解集合 $N(x)$；
3. **移动决策**：
   - 首个改进策略 (First Improvement)：遇到首个更优解立即移动；
   - 最佳改进策略 (Best Improvement)：遍历全部邻域解选择最优者移动；
4. **终止条件**：当前解严格优于邻域内所有解（达到局部极小）时终止。
### 约束处理
邻域移动算子仅在可行多面体内生成合法变换。
### 参数
邻域算子类型定义、邻域探索深度与采样上限。
### 验证
邻域遍历完备性检验、步数收敛分析。
### 风险
100% 陷入首次遭遇的局部最优陷阱，对初始解质量极度敏感。
### 场景
路线快速平滑优化、与 GA/PSO 构成混合模因算法 (Memetic Algorithm)。
### 比较
极其轻量快速，无全局跳出机制，通常作为 VNS、TS、SA、ALNS 等高级框架的基础算子。
