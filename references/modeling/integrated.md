# 综合类方法

## 灵敏度分析（OAT / Morris / Sobol）

### 适用性
量化输入参数的不确定性对系统输出变异的贡献度，识别主导因子与参数交互效应。局部灵敏度（OAT）适用于单点局部微扰；全局灵敏度（Morris 筛选法、Sobol 方差分解法）适用于全参数空间非线性与高维黑盒系统。

### 结构或公式
- 局部敏感度：$S_i = \frac{\partial Y / Y}{\partial X_i / X_i} = \frac{\partial \ln Y}{\partial \ln X_i}$
- Sobol 总方差分解：$V(Y) = \sum_i V_i + \sum_{i<j} V_{ij} + \dots + V_{1\dots k}$
- 一阶敏感度指数：$S_i = \frac{V_i}{V(Y)} = \frac{\text{Var}_{X_i}(E_{\mathbf{X}_{\sim i}}[Y|X_i])}{\text{Var}(Y)}$；全局总阶指数：$S_{Ti} = 1 - \frac{\text{Var}_{\mathbf{X}_{\sim i}}(E_{X_i}[Y|\mathbf{X}_{\sim i}])}{\text{Var}(Y)}$

### 算法专属步骤
1. 定义输入参数概率分布与取值边界，设定目标输出响应标量 $Y$。
2. 采样设计：OAT 采用基准值单向步进扰动；Morris 采用 $r$ 条随机轨迹网格抽样；Sobol 采用 Saltelli 准随机序列矩阵抽样（生成大小为 $N(2k+2)$ 的采样矩阵）。
3. 批量代入仿真/机理模型求解输出响应向量。
4. 指标计算：Morris 计算各参数初等效应的均值 $\mu_i^*$ 与标准差 $\sigma_i$；Sobol 计算一阶指数 $S_i$ 与全阶指数 $S_{Ti}$。
5. 绘制敏感度排序条形图与多参数交互散点图。

### 约束处理
- 参数间存在物理边界约束时采用变换抽样或拒绝采样；存在强共线性输入时改用相关输入方差分解（Kucherenko 指数）。

### 参数
- Sobol 基样本量 $N$（$500 \sim 2000$，总计算次数 $N(2k+2)$）；Morris 轨迹数 $r$（$10 \sim 50$）；OAT 扰动步长 $\Delta$（$\pm 5\% \sim \pm 10\%$）。

### 验证
- 采样收敛性验证（随 $N$ 增加指数波动 $< 5\%$）；Sobol 恒等式检验（$\sum S_i \le 1 \le \sum S_{Ti}$）。

### 风险
- Sobol 计算开销巨大，在耗时极长的黑盒仿真中不结合代理模型易超时；OAT 严重低估非线性交互。

### 场景
- 优化决策模型的鲁棒性与参数扰动分析；复杂机理系统关键敏感因子筛选与简化降阶。

### 比较
- OAT 计算最省但仅限局部；Morris 计算量适中用于快速粗筛；Sobol 理论最严密，可精确定量交互效应。

## 蒙特卡洛模拟（Monte Carlo Simulation）

### 适用性
通过大量伪随机或拟随机抽样统计试验，求解高维数值积分、复杂随机过程演化、不确定性传播及解析解难以推导的概率分布问题。

### 结构或公式
- 期望估计量：$\hat{\theta} = \frac{1}{N}\sum_{i=1}^N g(\mathbf{X}^{(i)})$
- 估计方差与误差收敛界：$\text{Var}(\hat{\theta}) = \frac{\sigma^2}{N}$，标准误差 $SE = \frac{\sigma}{\sqrt{N}} = O(N^{-1/2})$
- 置信区间（$1-\alpha$）：$\hat{\theta} \pm z_{1-\alpha/2} \frac{s}{\sqrt{N}}$

### 算法专属步骤
1. 明确系统确定性映射逻辑 $Y = g(X_1, X_2, \dots, X_p)$。
2. 拟合输入变量的先验概率分布（正态、均匀、指数、Beta 等）及协方差结构。
3. 随机抽样：利用拉丁超立方抽样（LHS）或伪随机数生成器产生 $N$ 组输入向量。
4. 向量化运行模型，收集 $N$ 次模拟的输出样本集 $\{Y^{(1)}, \dots, Y^{(N)}\}$。
5. 统计推断：计算输出的均值、分位数、概率密度直方图（KDE）及风险价值（VaR/CVaR）。

### 约束处理
- 相关变量抽样：利用 Cholesky 分解分解协方差矩阵或构建 Copula 联合分布函数。
- 极罕见失效事件（概率 $< 10^{-4}$）：采用重要性抽样（Importance Sampling）或子集模拟（Subset Simulation）加速收敛。

### 参数
- 抽样次数 $N$（常规模拟 $10^4 \sim 10^6$）；随机数种子 `random_state`；置信水平 $1-\alpha$（默认 0.95）。

### 验证
- 均值与方差随抽样量 $N$ 的动态收敛轨迹曲线；Bootstrap 重采样评估置信区间宽度。

### 风险
- 抽样次数不足导致尾部风险严重低估；输入分布假设主观偏离导致“垃圾进、垃圾出”（GIGO）。

### 场景
- 投资组合风险 VaR 度量与期权定价；设备可靠性寿命与供应链断供概率评估；交通流随机延误仿真。

### 比较
- 突破解析推导维数灾难，适应任意复杂逻辑；相比纯随机抽样，拉丁超立方抽样（LHS）方差显著更小。

## 系统动力学（System Dynamics）

### 适用性
分析包含多重高阶非线性因果反馈回路、时间延迟与存量流动特性的复杂社会、经济、生态系统的宏观长期动态演化。

### 结构或公式
- 存量-流量积分微分方程：$L_i(t) = L_i(t_0) + \int_{t_0}^t (\text{Inflow}_i(\tau) - \text{Outflow}_i(\tau)) d\tau$
- 状态更新微分形式：$\frac{dL_i(t)}{dt} = \text{Rate}_{\text{in}, i}(t) - \text{Rate}_{\text{out}, i}(t)$

### 算法专属步骤
1. 系统边界界定：识别内生变量、外生变量，绘制因果回路图（CLD，标明正负反馈极性）。
2. 构建存量流量图（SFD）：明确区分状态存量（Stock/Level）、变化流量（Flow/Rate）与辅助变量（Auxiliary）。
3. 建立数学方程式：定义初始状态 $L(t_0)$、各流量速率代数/微分方程及信息/物质延迟函数。
4. 模型标定：利用历史经验数据标定表函数（Table Function）与结构参数。
5. 数值积分仿真：设定步长 $dt$ 运行 Euler 或 RK4 仿真；设计不同政策调控情景对比仿真轨迹。

### 约束处理
- 非负存量约束：在出流速率方程中引入光滑截断函数 $\text{Rate}_{\text{out}} = \min(\text{DesiredRate}, \text{Stock}/dt)$。
- 消除代数环（Algebraic Loop）：引入微小信息延迟或显式状态存量解耦。

### 参数
- 仿真时限 $T$；计算步长 $dt \le \frac{1}{4} \times \text{系统最短延迟时间}$；积分方法（Euler、Runge-Kutta 4阶）。

### 验证
- 量纲一致性检验（Unit Consistency Check）；极端条件测试（如零库存、极限冲击下系统是否合理崩溃）；历史拟合 Theil 不等式系数检验。

### 风险
- 辅助变量参数主观臆造过多导致模型脱离现实；步长 $dt$ 过大引发虚假数值振荡。

### 场景
- 城市水资源-经济-环境复合承载力演化仿真；供应链牛鞭效应与库存波动控制；碳减排政策情景模拟。

### 比较
- 强调宏观因果机理与反馈结构，外推解释力远强于纯时序回归；相比多智能体（ABM）更加宏观高效。

## 常微分方程数值解（ODE）

### 适用性
求解随单一独立自变量（通常为时间 $t$）演化的连续物理、动力学、化学反应动力学系统的初值问题（IVP）与边值问题（BVP）。

### 结构或公式
- 一阶微分方程组标准型：$\frac{d\mathbf{y}}{dt} = \mathbf{f}(t, \mathbf{y}), \quad \mathbf{y}(t_0) = \mathbf{y}_0$
- 经典四阶 Runge-Kutta（RK4）：$\mathbf{y}_{n+1} = \mathbf{y}_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$
  其中 $k_1 = \mathbf{f}(t_n, \mathbf{y}_n)$, $k_2 = \mathbf{f}(t_n + \frac{h}{2}, \mathbf{y}_n + \frac{h}{2}k_1)$, $k_3 = \mathbf{f}(t_n + \frac{h}{2}, \mathbf{y}_n + \frac{h}{2}k_2)$, $k_4 = \mathbf{f}(t_n + h, \mathbf{y}_n + h k_3)$

### 算法专属步骤
1. 机理建模：根据牛顿定律、质量守恒等列出微分方程，将高阶 ODE 通过变量代换转化为一阶方程组。
2. 设定初值条件 $\mathbf{y}_0$ 与积分区间 $[t_0, t_{\text{end}}]$。
3. 刚性（Stiffness）诊断：评估雅可比矩阵 $J = \frac{\partial \mathbf{f}}{\partial \mathbf{y}}$ 特征值跨度。
4. 求解器选择：非刚性系统选用显式自适应 RK45（Dormand-Prince）；刚性系统选用隐式 Radau IIA 或 BDF 算法。
5. 积分求解与事件检测（Event Function，检测碰撞/越界触发条件）。
6. 参数未知时结合非线性最小二乘（如 `scipy.optimize.curve_fit`）反演参数。

### 约束处理
- 状态非负约束或守恒律约束：采用投影校正法（Projection Method）或保辛几何积分器（Symplectic Integrator）。

### 参数
- 相对容差 `rtol`（通常 $10^{-3} \sim 10^{-6}$）；绝对容差 `atol`（通常 $10^{-6} \sim 10^{-9}$）；最大步长 `max_step`。

### 验证
- 步长减半收敛性比对；系统物理不变量守恒性校验（如能量守恒误差 $< 10^{-5}$）；相图轨线稳定性分析。

### 风险
- 刚性方程误用显式算法导致数值爆炸或计算步长无限收缩死锁；混沌动力系统对初值极度敏感。

### 场景
- 无人机/导弹弹道轨迹运动学仿真；化学反应动力学各组分浓度演变；机械振动系统阻尼响应。

### 比较
- RK45 效率高精度好但遇刚性失效；隐式 BDF/Radau 需解非线性代数方程，计算单步开销大但无条件稳定。

## 偏微分方程数值解（PDE）

### 适用性
求解依赖空间多维（$x, y, z$）及时间（$t$）连续场的时空演化场方程（如温度场、扩散场、波动场、流体流速场）。

### 结构或公式
- 抛物型热传导方程：$\frac{\partial u}{\partial t} = \alpha \left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2}\right)$
- 双曲型波动方程：$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$；椭圆型 Poisson 方程：$\nabla^2 u = f(x, y)$
- 有限差分离散（二阶中心差分）：$\frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$

### 算法专属步骤
1. 确定 PDE 类型并明确空间几何域、初始条件与边界条件（Dirichlet 第一类、Neumann 第二类、Robin 第三类）。
2. 时空网格剖分：生成均匀/非均匀网格（有限差分网格或有限元三角/四面体网格）。
3. 离散格式构建：
   - 显式差分（FTCS）：直接前向迭代更新，受 CFL 条件约束。
   - 隐式差分（Crank-Nicolson）：构造稀疏三对角线性方程组，采用追赶法（Thomas 算法）逐层求解。
4. 空间边界条件代入边界节点方程。
5. 推进时步迭代求解全场未知量；绘制场分布云图、等高线图与剖面变化曲线。

### 约束处理
- 复杂不规则几何区域采用有限元法（FEM）或坐标变换；动边界/相变问题采用焓法（Enthalpy）或相场法。

### 参数
- 空间网格步长 $\Delta x, \Delta y$；时间步长 $\Delta t$；CFL 稳定性数 $C = \alpha \frac{\Delta t}{\Delta x^2} \le 0.5$（显式抛物型）。

### 验证
- 网格无关性验证（网格加密一倍后解的相对变化 $< 1\%$）；全场能量/质量通量积分守恒检验。

### 风险
- 显式格式违背 CFL 稳定性条件导致数值剧烈发散爆炸；网格过粗引发严重数值耗散与假扩散。

### 场景
- 高温作业专用服装隔热厚度设计（CUMCM 经典赛题）；地下水重金属污染物渗流扩散预测；雷达电磁散射场模拟。

### 比较
- 有限差分法（FDM）易实现适合规则矩形域；有限元法（FEM）与有限体积法（FVM）适合复杂几何边界与守恒律保证。

## SIR / SEIR 传染病动力学模型

### 适用性
描述传染病、舆情谣言、计算机病毒在封闭或开放群体网络中的传播扩散、潜伏阻滞与免疫康复动力学历程。

### 结构或公式
- SEIR 经典微分方程组：
  $$\frac{dS}{dt} = -\frac{\beta S I}{N}, \quad \frac{dE}{dt} = \frac{\beta S I}{N} - \sigma E, \quad \frac{dI}{dt} = \sigma E - \gamma I, \quad \frac{dR}{dt} = \gamma I$$
- 总人口守恒：$S(t) + E(t) + I(t) + R(t) \equiv N$
- 基本再生数：$R_0 = \frac{\beta}{\gamma}$（$R_0 > 1$ 疫情蔓延；$R_0 < 1$ 疫情自发消亡）

### 算法专属步骤
1. 仓室划分与机制扩展：界定易感者(S)、潜伏者(E)、感染者(I)、康复者(R)，按需扩展隔离(Q)、死亡(D)、疫苗接种(V)仓室。
2. 建立常微分方程组并推导平衡点与基本再生数 $R_0$。
3. 参数估计：利用疫情早期历史数据，通过非线性最小二乘或 MCMC 拟合接触率 $\beta$、潜伏转化率 $\sigma$、康复率 $\gamma$。
4. 数值求解：采用 RK45 积分求解各仓室随时间演化时序曲线。
5. 政策干预情景模拟：引入时变感染率 $\beta(t) = \beta_0 e^{-\kappa t}$ 模拟封控与疫苗接种效果，测算峰值到达时间与医疗负荷。

### 约束处理
- 各仓室非负约束 $S, E, I, R \ge 0$；总人口守恒约束；医疗床位饱和时设置康复率/死亡率分段函数。

### 参数
- 感染率 $\beta$；潜伏期倒数 $\sigma = 1/T_{\text{latent}}$；康复率 $\gamma = 1/T_{\text{infectious}}$；初始感染数 $I_0$。

### 验证
- 实际新增感染人数历史拟合优度（$R^2$ 与 RMSE）；疫情峰值与拐点时间吻合度。

### 风险
- 均匀混合假设忽略了社交网络拓扑异质性；疫情初期漏报瞒报导致参数 $\beta$ 估计严重失真。

### 场景
- 突发公共卫生疫情传播预测与防控资源调配；社交网络虚假新闻扩散与辟谣对冲演变。

### 比较
- SIR 忽略潜伏期适用于病程极短传染病；SEIR 增加潜伏仓室更贴近呼吸道传染病机理；网络动力学模型可进一步反映个体接触异质性。

## 排队论模型（Queuing Theory）

### 适用性
分析各类服务系统中的随机到达、等待排队与服务过程，评估队长、等待时间、服务台利用率等随机拥塞指标并优化系统容量。

### 结构或公式
- Kendall 记号：$A/B/c/k/m/Z$（到达分布/服务分布/服务台数/容量/顾客源/排队规则）
- $M/M/s$ 稳态服务强度：$\rho = \frac{\lambda}{s\mu} < 1$
- 稳态空闲概率：$P_0 = \left[ \sum_{n=0}^{s-1} \frac{(s\rho)^n}{n!} + \frac{(s\rho)^s}{s!(1-\rho)} \right]^{-1}$
- Little 定律：$L = \lambda W, \quad L_q = \lambda W_q, \quad W = W_q + \frac{1}{\mu}$

### 算法专属步骤
1. 收集系统运行数据，统计到达间隔时间分布与服务时长分布。
2. 分布拟合检验：利用 K-S 检验或卡方检验验证 Poisson 到达与负指数分布假设。
3. 判定排队系统类型（如 $M/M/1$, $M/M/s$, $M/M/s/K$），计算系统服务强度 $\rho$。
4. 代入稳态公式计算平均排队队长 $L_q$、系统总人数 $L$、平均等待时间 $W_q$、平均停留时间 $W$。
5. 建立经济效益优化模型：目标函数 $\min C(s) = C_1 s + C_2 L_q$（服务台成本 + 顾客排队等待损失），求解最优服务台数 $s^*$。

### 约束处理
- 系统稳定条件约束：$\rho < 1$（否则队列无限发散）；容量有限系统计算顾客因满载被拒绝的损失概率 $P_K$。

### 参数
- 平均到达率 $\lambda$；单服务台平均服务率 $\mu$；服务台数量 $s$；系统容量上限 $K$。

### 验证
- 离散事件仿真（DES，基于 SimPy 库）仿真结果与解析公式稳态指标对比验证。

### 风险
- 在到达率随时间剧烈波动（非齐次泊松过程，如早晚高峰）时套用稳态公式导致严重误判。

### 场景
- 医院急诊挂号窗口与医生排班优化；收费站/安检通道配置；云服务器请求并发排队缓冲池设计。

### 比较
- 经典解析公式求解极快且机理清晰；离散事件仿真适用于任意复杂非指数分布、动态时变到达与复杂优先级调度。

## 博弈论基础（Game Theory）

### 适用性
分析多个具有策略交互、利益制约与冲突对抗的理性决策主体在给定规则下的策略选择、利益均衡与长期演化稳定状态。

### 结构或公式
- 有限正规型博弈：$G = \{ N, (S_i)_{i\in N}, (u_i)_{i\in N} \}$
- 纳什均衡（Nash Equilibrium）：$\forall i \in N, \forall s_i \in S_i, \quad u_i(s_i^*, \mathbf{s}_{-i}^*) \ge u_i(s_i, \mathbf{s}_{-i}^*)$
- 演化博弈复制动态方程（Replicator Dynamics）：
  $$\frac{dx_i}{dt} = x_i (u(s_i, \mathbf{x}) - \bar{u}(\mathbf{x}))$$
- 合作博弈 Shapley 值：$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(|N|-|S|-1)!}{|N|!} (v(S \cup \{i\}) - v(S))$

### 算法专属步骤
1. 明确博弈局中人（Players）、策略空间（Strategies）与收益矩阵/效用函数（Payoff Function）。
2. 判定博弈类型：完全/不完全信息、静态/动态博弈、非合作/合作博弈或演化博弈。
3. 均衡求解：
   - 静态博弈：采用划线法或劣势策略消去法求纯策略纳什均衡；若无纯策略解，依据期望收益无差异原则列方程求解混合策略纳什均衡。
   - 动态博弈：绘制博弈树，采用逆向归纳法（Backward Induction）求解子博弈精炼纳什均衡。
   - 演化博弈：建立微分动力学系统，求解平衡点并利用雅可比矩阵局部稳定性分析求出演化稳定策略（ESS）。
4. 合作博弈：利用特征函数计算 Shapley 值或核仁进行联盟超额收益公平分摊。

### 约束处理
- 策略概率归一化约束：$\sum x_i = 1, x_i \ge 0$；合作博弈收益分配必须满足个体理性与集体理性。

### 参数
- 收益矩阵各支付参数；演化博弈初始群体比例 $(x_0, y_0)$；贴现因子 $\delta \in (0, 1)$。

### 验证
- 雅可比矩阵行列式 $\det(J) > 0$ 且迹 $\text{tr}(J) < 0$ 验证 ESS 渐近稳定性；Shapley 公理化性质校验。

### 风险
- 强行套用完全理性假设导致结论脱离人类真实行为；收益矩阵参数人为随意设定导致均衡结论缺乏可信度。

### 场景
- 碳排放交易市场中政府监管与企业减排策略演化；电商平台定价价格战博弈；供应链产销联盟收益分摊。

### 比较
- 传统纳什均衡强调一次性静态完全理性；演化博弈强调有限理性与群体长期动态学习；合作博弈专注联盟共赢分配。
