## 稳定的 C 题画像

八年跨度很大，但 C 题有比题目名称更稳定的结构：

1. **数据不是结果，数据只是建模起点。** 往往先需要处理缺失、异常、口径、重复记录、类别编码或时间尺度。
2. **第一问常负责建立数据事实或基础关系。** 后续问题应尽量复用这些关系，而不是重新起炉灶。
3. **最终通常需要可执行决策。** 例如会员分类、出租车策略、信贷额度、订购量、样本类别、补货价格、种植方案、检测时机。
4. **统计与优化经常连在一起。** 预测精度不是终点，预测结果需要进入收益、风险或资源配置模型。
5. **实际约束比算法更重要。** 作物轮作、交易损耗、企业额度、检测窗口、供应稳定性等业务约束决定模型是否像“真实问题”。
6. **不确定性越来越重要。** 参数估计、样本量、预测区间、风险偏好、价格/产量波动会影响最终动作。

## 从题型到模型链

### 数据画像/分类型

数据清洗 → 指标构造 → 降维/聚类 → 分类验证 → 群体解释 → 决策建议。

### 预测 + 优化型

探索规律 → 预测关键输入 → 构造收益/损失 → 建立约束优化 → 情景/鲁棒分析。

### 统计推断 + 决策型

统计模型 → 参数/风险估计 → 临界条件 → 分组/判定 → 决策损失 → 不确定性传播。

### 大规模规划型

业务约束翻译 → 基础规划模型 → 结构化简 → 求解器/启发式 → 多情景 → 稳健性。

## 不应机械继承

- 2018 用过聚类，不代表新的客户问题一定需要 K-means。
- 2024 用过差分进化/遗传等求解，不代表所有整数规划都应先上元启发式。
- 2025 存在医学统计，不代表普通预测题应使用复杂生存/混合模型。
- 某年专家点评的一条建议只对当年赛题成立时，不应升级成硬规则。

真正应继承的是：**数据口径严谨、模型动机明确、主线连续、结果可解释、最终可决策、误差会传递。**
