# C 题模型与算法工具箱

## 1. 先问四个问题

选择任何算法前先回答：

1. 输出是“解释关系、预测数值、判别类别、评价排序，还是做决策”？
2. 数据是横截面、时间序列、重复测量、面板、空间数据还是组合决策数据？
3. 误差结构是什么：连续、计数、二分类、比例、删失、偏态、重尾？
4. 最终结论对误差有多敏感？

## 2. 数据预处理

### 必做审计
- 缺失值：缺失机制、比例、是否可插补。
- 异常值：先定位业务原因，再决定保留、截尾、修正或剔除。
- 重复记录：区分重复交易、重复测量和数据重复。
- 单位与口径：价格/销量/面积/时间必须统一。
- 类别变量：保留可解释编码。
- 时间泄漏：预测问题禁止使用未来信息构造训练特征。

### 常用方法
- IQR/MAD/Z-score（先看分布再选）；
- Winsorization 仅在有业务理由时；
- 插值、KNN/多重插补按缺失机制选；
- 标准化/归一化用于距离模型，回归中保留原始尺度便于解释时不必强制。

## 3. 探索与关系分析

| 目的 | 首选 | 升级条件 |
|---|---|---|
| 两连续变量关系 | Pearson/Spearman + 散点/局部拟合 | 明显非线性时样条/GAM |
| 类别差异 | t/ANOVA 或非参数检验 | 多因素时回归/方差模型 |
| 高维结构 | PCA/因子分析 | 非线性流形确有必要时再用 UMAP 等 |
| 客群分群 | 层次聚类/K-means/GMM | 形状复杂或噪声多才考虑 DBSCAN |
| 特征筛选 | 相关、VIF、LASSO、树重要性 | 用稳定性选择验证结果 |

相关性不能直接写成因果性。若业务叙事涉及机制，至少讨论潜在混杂因素或使用滞后/控制变量进行支持。

## 4. 回归与预测

### 解释优先
- 线性/多项式回归；
- Logistic/Probit；
- Poisson/负二项计数模型；
- GAM 用于平滑非线性；
- 混合效应用于个体重复测量/分层数据。

### 预测优先
- 指数平滑、ARIMA、状态空间；
- 随机森林、SVM、XGBoost；
- 时间序列交叉验证，不能随机打乱未来。

深度学习只有在样本规模、输入结构和效果增益都足够时使用；国赛 C 题小中型表格数据默认不优先。

## 5. 分类与鉴别

- Logistic：可解释基线；
- LDA/QDA：分布假设适用时；
- 决策树：规则可视化；
- RF/XGBoost：非线性表格数据；
- SVM：中小样本高维边界；
- 聚类不能替代有标签分类。

评价至少考虑混淆矩阵、Precision/Recall/F1/AUC；类别不平衡时不要只报告 Accuracy。

## 6. 评价与排序

AHP、熵权、TOPSIS不是“有指标就上”。优先检查：
- 指标是否重复；
- 权重是否有业务含义；
- 排名是否对权重敏感；
- 是否存在一个可直接建模的真实目标函数。

能直接用利润、风险、损耗、交付率等目标时，不要先制造综合评分。

## 7. 优化与决策

### 首选
- LP/MILP/MINLP；
- 动态规划；
- 网络流；
- 指派/运输/背包；
- 多目标规划与 ε-constraint；
- 情景规划、鲁棒优化。

### 元启发式使用条件
只有当模型非凸、组合规模过大、求解器难以直接处理或需要独立验证时，才考虑 GA/PSO/SA/DE/ACO。

写法：先给**数学模型**，再介绍算法。禁止以“算法流程”代替模型。

## 8. 风险与不确定性

- Bootstrap：估计参数/指标分布；
- Monte Carlo：传播复杂随机性；
- 情景分析：有限宏观状态；
- CVaR：尾部风险确实有业务意义；
- 鲁棒优化：参数区间可辨认且保守性有价值；
- 贝叶斯：先验/后验能改变决策且样本不确定性重要；
- 信息价值：额外采样是否值得。

## 9. “常用方法 + 关键创新”的推荐组合

优秀 C 题往往不是全篇高阶：

- Q1：描述统计 + 相关/回归，先把事实说清楚；
- Q2：基于 Q1 建预测/分类；
- Q3：把预测输入优化模型；
- Q4：针对不确定性、风险或现实限制做升级。

高级方法最好出现在“基础模型有明确缺口”的地方，形成 M0 → M1 的升级证据。
