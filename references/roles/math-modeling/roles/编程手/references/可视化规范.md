# 可视化规范

## 三类图

1. 原始数据图：分布、时间趋势、空间结构、相关性和异常点。
2. 模型运行过程图：收敛、训练、残差、灵敏度、消融和约束状态。
3. 模型最终结果图：方案、预测、排名、误差和不确定性。

候选图多多益善，不设置最多图数。论文手和用户按叙事需要选择。

## 通用要求

- 默认不使用网格线。
- 标题、坐标轴、图例、单位和数据范围必须正确。
- 颜色语义在全项目一致，并兼顾色觉可达性。
- 保存 SVG 和 300 DPI PNG；不要只调用 `show()`。
- 统计量、置信区间和 p 值必须由代码从当前数据计算，禁止硬编码。
- 置信区间不能用标准差冒充；函数应接收已计算的上下界，或根据明确的统计模型计算。
- HTML 面板位于 `figures/` 时，图路径写 `figure.svg`，不能写 `figures/figure.svg`。

## 两个子图示例（Python）

```python
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(10, 4), constrained_layout=True)
axes[0].plot(x, raw_values, color="#0F4D92")
axes[0].set(title="原始数据", xlabel="时间", ylabel="观测值")
axes[1].plot(x, predicted, color="#D1495B", label="预测")
axes[1].fill_between(x, lower_ci, upper_ci, color="#D1495B", alpha=0.16, label="95% CI")
axes[1].set(title="预测结果", xlabel="时间", ylabel="预测值")
axes[1].legend(frameon=False)
fig.savefig("figures/result_prediction.svg", bbox_inches="tight")
fig.savefig("figures/result_prediction.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

## 统计标注示例（Python）

```python
from scipy import stats

statistic, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)
label = f"Welch t-test: p={p_value:.3g}"
ax.text(0.98, 0.98, label, transform=ax.transAxes, ha="right", va="top")
```

## 两个子图示例（MATLAB）

```matlab
layout = tiledlayout(1, 2, "TileSpacing", "compact", "Padding", "compact");

nexttile;
plot(x, rawValues, "LineWidth", 1.4);
xlabel("时间"); ylabel("观测值"); title("原始数据");

nexttile;
hold on;
fill([x; flipud(x)], [lowerCI; flipud(upperCI)], [0.82 0.25 0.31], ...
    "FaceAlpha", 0.16, "EdgeColor", "none");
plot(x, predicted, "Color", [0.82 0.25 0.31], "LineWidth", 1.4);
xlabel("时间"); ylabel("预测值"); title("预测结果");
hold off;

exportgraphics(layout, "figures/result_prediction.png", "Resolution", 300);
exportgraphics(layout, "figures/result_prediction.svg", "ContentType", "vector");
close(gcf);
```

不要调用 `grid on`。如某个特殊图确需参考线，应只画有明确数值意义的 `xline`、`yline` 或零线，并在图注解释。
