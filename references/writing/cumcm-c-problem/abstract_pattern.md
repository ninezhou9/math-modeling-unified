# 摘要写作模板（只模仿结构，不复制范文文字）

## 开头

[真实场景] 的核心矛盾在于 [目标A] 与 [目标B] 同时受到 [关键数据/机制] 的影响，直接采用 [朴素做法] 容易造成 [具体问题]。本文围绕 [统一目标]，依次从 [基础规律]、[预测/分类]、[优化决策] 和 [不确定性] 建立递进模型。

## 问题一

针对问题一，考虑到 [数据特征/业务约束]，直接使用 [不合适方法] 难以 [原因]，因此首先 [关键预处理/定义]，建立 **[主模型]**。通过 [求解/估计] 得到 [1项核心结果]，并利用 [验证] 检验其合理性。

## 问题二

针对问题二，在问题一得到的 [参数/关系] 基础上，为描述 [新增困难]，建立 **[主模型]**，通过 [方法] 得到 [核心结论]。结果表明 [一句实际意义]。

## 其余问题

保持同一节奏：**动机 → 方法 → 核心结果 → 验证/意义**。

## 禁止

- 不要“针对问题一——”。
- 不要一段塞 5 个算法名。
- 不要罗列全表数字。
- 不要写软件操作。
- 不要只写“采用某算法”，却不说明为什么适合。
