# 写作证据门禁规范

当需要检查从模型、代码和结果到论文语言的细粒度映射时，读取保留的[CUMCM 写作证据门禁补充](workspace/CUMCM写作证据门禁补充.md)；本页仍是统一执行入口。

本文件是论文写作的严谨证据约束规范。将任何内容写入论文草稿前必须严格遵守本规范，杜绝无证据结论与套话。

```yaml
traceability_chain:
  - code
  - raw_output
  - figure_or_table
  - paper_claim
forbidden_unsupported_words:
  - 显著
  - 最优
  - 稳健
  - 大幅提高
  - 高度吻合
  - 完美
model_switch_condition: actual_failure_evidence_required
```

## 写作前事实包（10 项最小清单）

在动笔撰写任何章节前，必须具备以下 10 项事实输入；缺失任一项必须标为"待确认"，严禁自行脑补：

1. **题目原始要求与问题边界**（明确输入、输出与目标）。
2. **经过真实运行的计算代码**（无语法错误、可一键复现）。
3. **真实运行产生的原始控制台输出/数据表格**（带时间戳或日志）。
4. **生成的规范图表文件**（图内无标题、期刊配色、符合分辨率）。
5. **模型核心公式与符号的准确定义及单位**。
6. **基线模型（Baseline）的实验指标与表现**。
7. **进阶/复杂模型的实验指标与提升幅度**。
8. **误差分布与具体异常样本/区间的定位数据**。
9. **灵敏度/扰动分析的量化结果**。
10. **最终决策方案的具体数值与业务解释**。

## 核心写作门禁

### 1. 段落功能门禁
每个正文段落必须具备明确的学术功能（定义、理由、建模、求解、结果、解释、局限），禁止无实质信息的纯过渡段落与套话。

### 2. 公式叙述闭环
每个核心公式必须形成叙事闭环：
- 解决什么物理/业务问题。
- 理论来源与机理依据。
- 成立的前置假设条件。
- 符号与物理单位定义。
- 在后续计算中的具体作用。

### 3. 模型构建叙事链
现实机制 → 抽象提炼 → 变量关系 → 约束条件 → 求解算法 → 验证方案，逐层推导，禁止突兀给出公式。

### 4. 结果分析五要素
每个实验结果或表格/图表必须包含：
1. **证据**：指向具体图表编号（如"见表 3-1"）。
2. **现象**：客观描述数据走势或特征。
3. **幅度**：给出具体数值与百分比变化。
4. **参照**：与基线或理论值对比。
5. **解释与回应**：用机理或现实意义解释原因，并明确回应子问题要求。

### 5. 误差定位与归因
- 精确定位误差发生的样本、时间段或参数区间，禁止含糊写"存在一定误差"。
- 区分系统误差与随机误差。
- 从数据质量、假设近似、参数估计、算法精度四个维度进行归因分析。

### 6. 多模型比较语言
- 必须基于多维准则（精度、时间复杂度、可解释性、稳健性）对比。
- **模型切换硬门禁**：仅在记录了基础/简单模型的实际失败或精度不足实验证据后，才允许切换或引入更复杂的模型（`actual_failure_evidence_required`）。

### 7. 可追溯性链条（Traceability Chain）
结论声明（`paper_claim`）必须严格依循：
`code`（可运行代码） → `raw_output`（真实原始输出） → `figure_or_table`（图表呈现） → `paper_claim`（论文定论）。

### 8. 强判断词证据检查
严格拦截以下词汇的无证据滥用：
- `显著`：必须附带假设检验统计量及 $p$ 值（如 $t = 3.45, p < 0.01$）。
- `最优`：必须证明满足一阶/二阶最优化条件或列出候选解空间搜索全景。
- `稳健`：必须附带参数扰动 $\pm 10\%$ 以上的灵敏度指标变化区间。
- `大幅提高`：必须给出具体提升百分比（如"准确率提升 14.2%"）。
- `高度吻合`：必须给出拟合优度 $R^2$、RMSE 或 MAPE 等量化指标。
- `完美`：严禁使用主观夸大修饰词。

### 9. 语言自然度与客观性
- 使用客观主语（"计算结果表明"、"由式(4)可知"），避免滥用第一人称"我们"。
- 删除套话、机械排比和无意义的口号式语句。

## 立即阻断退回条件

遇到以下情况必须立即停止写作并退回上游角色：
1. 缺少代码实际运行结果。
2. 论文引用的图表在目录中不存在或数值与代码输出不符。
3. 试图在没有失败证据的情况下直接使用黑盒复杂模型。
4. 核心变量未定义物理单位。
5. 结论出现未经验证的强断言。
