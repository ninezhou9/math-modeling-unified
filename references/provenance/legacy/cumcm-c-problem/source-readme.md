# CUMCM C Problem

专门服务于**全国大学生数学建模竞赛本科组 C 题**的建模与论文生产工作流。

## 我们的优势

- **C 题专用**：基于 2018–2025 年官方 C 题优秀论文展示、赛题讲评与评阅规范提炼，不做 A/B 题式泛化。
- **问题结构决定模型**：优先统计分析、数据建模、预测、评价与优化等国赛常用方法，只在关键瓶颈使用高级算法。
- **呈现驱动建模**：从建模阶段同步设计总览图、核心规律图、策略相图、误差图和最终方案表，让评委快速看懂思想与结果。
- **论文结构稳定**：严格沿用 `cumcmthesis` 模板体系，固定章节节奏与写法；摘要与关键词独占第一页，关键词不超过 5 个。
- **25–28 页主论文目标**：在当年官方页数上限允许时，默认将摘要、正文和参考文献控制在 25–28 页，拒绝空洞凑页。
- **评委视角终检**：同时检查数学正确性、模型必要性、创新是否可见、结果是否可执行、图表是否承担信息任务、代码是否可复现。
- **合规优先**：每次实战先刷新当年 CUMCM 官方规则；专家讲评和历史评分经验只作为高优先级建议，不作为死规则。

> 核心原则：**当前赛题优先，数学正确性优先，合适方法优先；关键处创新，全文靠叙事与呈现放大价值。**

## 目录

- `SKILL.md`：C 题主工作流
- `references/`：近八年 C 题规律、专家讲评、评阅机制、模型工具箱、论文结构、可视化规范与终检清单
- `assets/template/`：用户指定的 CUMCM LaTeX 模板与论文骨架
- `scripts/`：项目初始化与论文结构/页数/图表/LaTeX 自动检查

## 资料说明

官方展示的优秀论文与专家讲评页面中多处明确标注“未经许可请勿转载/请勿下载”。因此本仓库**不重新分发原始论文 PDF、页面图片或专家 PPT**，只保存官方来源索引和基于研读形成的原创方法总结。需要复核原文时请访问 `references/source-index.md` 中的官方页面。
